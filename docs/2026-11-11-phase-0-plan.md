# OpenZone Trader, Phase 0: Repository and Inventory Probe — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `openzone-trader` repository and a stand probe that answers, on a live 1.30 stand with a client connected, the inventory questions the trader's deal depends on (design §12 items 1-7, 11, 13 and the slot half of 12), then write the answers into the skills and correct the design.

**Architecture:** Two stand-only pbos that are never published. `OpenZone_TraderProbe` loads on both sides: stand-in wallet, banknote and wear-slot classes, an op engine on the server, an inventory dump on the client. `OpenZone_TraderProbe_Bridge` loads on the server only and adds the verb `ozt_probe` to the MCP bridge, so every measurement is one `world_exec` call. An op writes its full report to a results file in the server profile; the verb's own answer is a summary, because the bridge cuts it at 400 characters. The stand loads no Workshop mod and runs on its own world instance.

**Tech Stack:** Enforce Script on DayZ 1.30.164289 (diag build), the `dayz` MCP server (`project_open`, `mod_lint`, `mod_build`, `server_start`, `log_verdict`, `client_start`, `world_exec`, `client_shot`), git.

**Design:** `E:\openzone\docs\specs\2026-11-10-openzone-trader-design.md` (§4 the deal, §5 the inventory model, §6 items with parts, §7 money, §12 what to measure, §13 phases). Decision 4 of its §14 (bought gear straight onto a free slot) is still marked "to confirm"; this phase measures slot creation either way and is not blocked by it.

- A refusal by the engine is an answer, not a failed command: an op answers `DONE` with what the engine said. `FAILED` is for a command that could not be understood.
- Every stand run ends with the telling screenshots sent to the owner with `SendUserFile` (one line of caption each).
- A measured engine fact goes into the `dayz-modding` skill with neutral names (`MyMod_`, "a stand mod"); the pointer to our code goes into the `openzone` skill. `python -I openzone/scripts/check-generic.py`, run from `E:\dayzmod\dayz-modding-skill`, must print nothing before `dayz-modding` is committed.

## What is known before this phase, and what is still open

The storage work already measured part of §12, on an unannounced server-local container. Do not measure it again; measure what differs for a living player's worn inventory with a client watching.

| question | known (where) | open here |
|---|---|---|
| creating at a cell | `LocationCreateEntity` with `SetCargo` puts an item at an explicit cell; `CreateEntityInCargoEx` returns the entity whether or not it honoured the cell (`dayz-modding`, items-and-processing, "CreateEntityInCargoEx returns the entity...") | worn containers of a player: cell and flip honoured, a taken cell, a cell past the edge, what the client holds afterwards |
| deleting | `ObjectDelete` is deferred to the end of the frame (same file, "A weapon draws its magazine only when told to") | whether the freed cell can be used in the same script call; `Delete()` and `DeleteSafe()` latency |
| occupancy | read from each item's own location, never from `CargoBase.GetItemRowCol` (`openzone-storage`, `OZS_Ops.c`, `Where` and `Occupant`) | whether a map built that way agrees with the engine cell by cell on worn containers |
| script gates | a LOCAL move asks no script gate; `CanAddEntityInCargo[Ex]` does (items-and-processing, "A LOCAL move does not ask the script gates") | `TestAddEntityInCargoEx` flag by flag with a probe entity, and its cost |
| nested containers | a `Container_Base` lying in cargo refuses children from every script path (persistence-networking, "A container lying in cargo refuses children from script too") | a wallet that is an `Inventory_Base` whose receive gate never asks its parent class, which is how the reference server's wallet is written |
| server moves | `TakeToDst(SERVER)` tells the clients and `LocationSyncMoveEntity` does not; a move onto a taken cell answers true and does nothing; on 1.29 a move landed after the frame that asked (items-and-processing, "Server-side moves land AFTER the frame that asked") | 1.30 timing on a player's items; attachments off weapons; sources whose script gate says no |
| magazines | a pile is quantity 1 plus an ammo count; `ServerSetAmmoCount` (items-and-processing, "The panel draws a magazine's number...") | created with a count, the client's number, the weapon's state after `CreateAttachment` against `Weapon_Base.SpawnAttachedMagazine` |

Two items of §12 are settled by design rather than by measurement, and Task 8 writes that into the design:

- "a client drag in flight" (item 2): the trade screen is the only open menu during a deal, so nothing can be dragged in the vanilla inventory. What remains is a server-side check before the commit, and vanilla has it: `PlayerBase.CanDeleteItems()` (no throw animation, `GetDayZPlayerInventory().IsProcessing()` false, no running action) and `g_Game.HasInventoryJunctureItem(item)`. Task 4 reads both.
- "vehicle" (item 5): the plan treats the hands as busy while the player is in a vehicle. Nothing is created in the hands there, so nothing is measured.

### Reading a result

- The verb's answer is a summary that ends with `[#<n>]`. The full report of command `n` is in `E:\dayzmod\testserver\profiles\OpenZone_TraderProbe\results.log` under the line `=== #<n>`.
- Items an op watches leave lines `watch #<n> ...` in the same file for three seconds after the op: every change of place with the milliseconds and server frames since the op, and a closing line `ends`.
- Reading "frames": inside one engine frame the mission update comes first (`DayZGame.OnUpdate` calls `mission.OnUpdate`, where the probe's watches and queued jobs run) and the system call queue after it (where the bridge runs an op, and where `Object.Delete()` queues its `ObjectDelete`). So a watch line at "1 frames" and a job queued with `frames=1` both belong to the start of the very next engine frame, before that frame's call queue.
- Read the tail with: `tail -n 80 /e/dayzmod/testserver/profiles/OpenZone_TraderProbe/results.log`

```c
// Shared by both sides of the probe: files under $profile:OpenZone_TraderProbe

class OZT_ProbeLog
{
    static const string DIR = "$profile:OpenZone_TraderProbe";

    static void EnsureDir()
    {
        MakeDirectory(DIR);
    }

    static void Append(string fileName, string line)
    {
        FileHandle fh = OpenFile(DIR + "/" + fileName, FileMode.APPEND);
        if (!fh)
            return;
        FPrintln(fh, line);
        CloseFile(fh);
    }

    static void WriteAll(string fileName, array<string> lines)
    {
        FileHandle fh = OpenFile(DIR + "/" + fileName, FileMode.WRITE);
        if (!fh)
            return;
        for (int i = 0; i < lines.Count(); i++)
            FPrintln(fh, lines.Get(i));
        CloseFile(fh);
    }

    static string B(bool v)
    {
        if (v)
            return "yes";
        return "no";
    }

    // One decimal, as text.
    static string R1(float v)
    {
        float r = Math.Round(v * 10) / 10;
        return r.ToString();
    }
}
```

```c
// The reading side of the trader probe: how an item is named in a report, where
// it stands, and the occupancy of a cargo.
//
// Occupancy is built from each item's OWN inventory location. CargoBase.
// GetItemRowCol is not used: on 1.29 it answered cells that were not the item's.
class OZT_ProbeInv
{
    // "<netid> <Type>". The network id is the same number on the server and on
    // every client, which is what lets two dumps be compared line by line.
    static string Name(EntityAI e)
    {
        if (!e)
            return "null";
        return e.GetNetworkIDString() + " " + e.GetType();
    }

    // The unturned size of an item, as the engine holds it for the entity.
    static void SizeOf(EntityAI e, out int w, out int h)
    {
        w = 0;
        h = 0;
        if (!e)
            return;
        GetGame().GetInventoryItemSize(InventoryItem.Cast(e), w, h);
    }

    // The size a CLASS declares in config, looked up in the three roots an item
    // can live in. This is what a plan has before the item exists.
    static bool ConfigSize(string type, out int w, out int h)
    {
        w = 0;
        h = 0;
        array<string> roots = {"CfgVehicles", "CfgWeapons", "CfgMagazines"};
        for (int i = 0; i < roots.Count(); i++)
        {
            string path = roots.Get(i) + " " + type + " itemSize";
            if (!GetGame().ConfigIsExisting(path))
                continue;
            TIntArray size = new TIntArray();
            GetGame().ConfigGetIntArray(path, size);
            if (size.Count() == 2)
            {
                w = size.Get(0);
                h = size.Get(1);
                return true;
            }
        }
        return false;
    }

    // Where an item stands, as text that reads the same on both sides.
    static string Where(EntityAI e)
    {
        if (!e)
            return "GONE";
        if (!e.GetInventory())
            return "NOINV";
        InventoryLocation il = new InventoryLocation();
        if (!e.GetInventory().GetCurrentInventoryLocation(il))
            return "NOLOC";
        int lt = il.GetType();
        string parent = "none";
        if (il.GetParent())
            parent = il.GetParent().GetType() + "#" + il.GetParent().GetNetworkIDString();
        if (lt == InventoryLocationType.CARGO || lt == InventoryLocationType.PROXYCARGO)
        {
            string s = "CARGO " + parent + " r" + il.GetRow().ToString() + " c" + il.GetCol().ToString();
            s = s + " flip=" + OZT_ProbeLog.B(il.GetFlip());
            return s;
        }
        if (lt == InventoryLocationType.ATTACHMENT)
            return "ATT " + parent + " slot=" + InventorySlots.GetSlotName(il.GetSlot());
        if (lt == InventoryLocationType.HANDS)
            return "HANDS " + parent;
        if (lt == InventoryLocationType.GROUND)
            return "GROUND";
        return "LOCTYPE" + lt.ToString();
    }

    // How much there is of it, the way the inventory screen counts: rounds for
    // anything that is a magazine (weapon magazines and ammunition piles alike),
    // the item's own quantity otherwise.
    static string Amount(EntityAI e)
    {
        Magazine mag = Magazine.Cast(e);
        if (mag)
            return "ammo " + mag.GetAmmoCount().ToString() + "/" + mag.GetAmmoMax().ToString();
        ItemBase ib = ItemBase.Cast(e);
        if (ib && ib.HasQuantity())
            return "qty " + OZT_ProbeLog.R1(ib.GetQuantity()) + "/" + ib.GetQuantityMax().ToString();
        return "-";
    }

    // One line of a dump.
    static string Line(EntityAI e)
    {
        int w;
        int h;
        SizeOf(e, w, h);
        string s = Name(e) + " | " + Where(e) + " | " + w.ToString() + "x" + h.ToString();
        s = s + " | " + Amount(e);
        return s;
    }

    // Everything the character carries, one line each, sorted, so that the
    // server's file and a client's file can be compared with a plain diff.
    static void Tree(PlayerBase player, array<string> lines)
    {
        array<EntityAI> items = new array<EntityAI>();
        player.GetInventory().EnumerateInventory(InventoryTraversalType.PREORDER, items);
        for (int i = 0; i < items.Count(); i++)
        {
            EntityAI e = items.Get(i);
            if (!e || e == player)
                continue;
            lines.Insert(Line(e));
        }
        lines.Sort();
    }

    // The cargo of `holder` as a grid of taken cells, row by row. False when the
    // holder has no cargo. `skip` is left out of the map: an item that is about
    // to leave does not stand in its own way.
    static bool Map(EntityAI holder, EntityAI skip, out array<bool> taken, out int gw, out int gh)
    {
        gw = 0;
        gh = 0;
        taken = new array<bool>();
        if (!holder || !holder.GetInventory())
            return false;
        CargoBase cargo = holder.GetInventory().GetCargo();
        if (!cargo)
            return false;
        gw = cargo.GetWidth();
        gh = cargo.GetHeight();
        int cells = gw * gh;
        for (int k = 0; k < cells; k++)
            taken.Insert(false);
        int n = cargo.GetItemCount();
        for (int i = 0; i < n; i++)
        {
            EntityAI it = cargo.GetItem(i);
            if (!it || it == skip)
                continue;
            InventoryLocation il = new InventoryLocation();
            if (!it.GetInventory().GetCurrentInventoryLocation(il))
                continue;
            int w;
            int h;
            SizeOf(it, w, h);
            if (il.GetFlip())
            {
                int turned = w;
                w = h;
                h = turned;
            }
            for (int r = il.GetRow(); r < il.GetRow() + h; r++)
            {
                for (int c = il.GetCol(); c < il.GetCol() + w; c++)
                {
                    if (r >= 0 && r < gh && c >= 0 && c < gw)
                        taken.Set(r * gw + c, true);
                }
            }
        }
        return cells > 0;
    }

    // Is the w x h rectangle at row, col inside the grid and free?
    static bool RectFree(array<bool> taken, int gw, int gh, int row, int col, int w, int h)
    {
        if (row < 0 || col < 0 || w <= 0 || h <= 0)
            return false;
        if (row + h > gh || col + w > gw)
            return false;
        for (int r = row; r < row + h; r++)
        {
            for (int c = col; c < col + w; c++)
            {
                if (taken.Get(r * gw + c))
                    return false;
            }
        }
        return true;
    }
}
```

```c
// The server-side op engine of the trader probe.
//
// One op per bridge command, answered within the tick that carries it. An op
// gathers its lines with AddLine; Command writes them under `=== #<n>` in
// results.log and hands the bridge a one-line summary (the bridge cuts a
// summary at 400 characters, which is why the report lives in a file).
//
// Three things outlive an op and are driven from MissionServer.OnUpdate:
//   handles  names for items, given by dress / find / create, used by later ops;
//   watches  an item's place, written to results.log every time it changes for
//            three seconds after the op -- this is how "the same call", "the
//            next frame" and "some frames later" are told apart;
//   later    one creation or deletion queued for a named server frame.

class OZT_ProbeWatch
{
    EntityAI m_Item;        // weak: reads null once the engine destroyed the entity
    string   m_Label;
    string   m_Last;
    float    m_StartedAt;
    float    m_CheckedAt;
    int      m_StartFrame;
    int      m_Seq;
}

class OZT_ProbeLater
{
    int      m_DueFrame;
    int      m_Seq;
    string   m_Kind;        // "create" or "delete"
    string   m_Class;
    string   m_Handle;
    EntityAI m_Target;      // create: the holder; delete: the item
    int      m_LocType;
    int      m_Row;
    int      m_Col;
    int      m_Slot;
    bool     m_Flip;
}

class OZT_Probe
{
    static const float  WATCH_SECONDS = 3.0;
    static const string RESULTS = "results.log";

    protected static ref OZT_Probe s_Instance;

    protected ref map<string, EntityAI>      m_Handles;
    protected ref array<ref OZT_ProbeWatch>  m_Watches;
    protected ref array<ref OZT_ProbeLater>  m_Later;
    protected ref array<string>              m_Lines;
    protected int m_Seq;
    protected int m_Frame;

    static OZT_Probe Get()
    {
        if (!s_Instance)
            s_Instance = new OZT_Probe();
        return s_Instance;
    }

    void OZT_Probe()
    {
        m_Handles = new map<string, EntityAI>();
        m_Watches = new array<ref OZT_ProbeWatch>();
        m_Later = new array<ref OZT_ProbeLater>();
        m_Lines = new array<string>();
    }

    int FrameNo()
    {
        return m_Frame;
    }

    int SeqNo()
    {
        return m_Seq;
    }

    // ---- the bridge's entry point -------------------------------------------

    bool Command(string op, map<string, string> args, out string detail)
    {
        m_Seq++;
        m_Lines.Clear();
        bool ok = RunOp(op, args, detail);

        string head = "=== #" + m_Seq.ToString() + " " + op + " ok=" + OZT_ProbeLog.B(ok);
        head = head + " frame=" + m_Frame.ToString() + " t=" + OZT_ProbeLog.R1(GetGame().GetTickTime());
        head = head + " args:" + ArgsText(args);
        OZT_ProbeLog.Append(RESULTS, head);
        OZT_ProbeLog.Append(RESULTS, "    " + detail);
        for (int i = 0; i < m_Lines.Count(); i++)
            OZT_ProbeLog.Append(RESULTS, "    " + m_Lines.Get(i));

        // Nothing of the report goes to the script log: a class name or an
        // engine answer could carry a word the log verdict fails a boot on.
        Print("[OpenZone] trader probe #" + m_Seq.ToString() + " " + op + " finished");
        detail = detail + " [#" + m_Seq.ToString() + "]";
        return ok;
    }

    protected bool RunOp(string op, map<string, string> args, out string detail)
    {
        if (op == "status")
            return OpStatus(detail);

        PlayerBase player = FirstPlayer();
        if (!player)
        {
            detail = "nobody is connected: start a client first";
            return false;
        }

        // -- routes of the later tasks go above this line --
        detail = "unknown op '" + op + "'; known: " + KnownOps();
        return false;
    }

    protected string KnownOps()
    {
        return "status";
    }

    protected bool OpStatus(out string detail)
    {
        array<Man> men = new array<Man>();
        GetGame().GetPlayers(men);
        detail = "trader probe: players=" + men.Count().ToString() + " frame=" + m_Frame.ToString();
        detail = detail + " handles=" + m_Handles.Count().ToString() + " watches=" + m_Watches.Count().ToString();
        return true;
    }

    // ---- what the ops share ---------------------------------------------------

    void AddLine(string line)
    {
        m_Lines.Insert(line);
    }

    string ArgOf(map<string, string> args, string key, string fallback)
    {
        if (!args)
            return fallback;
        string v;
        if (args.Find(key, v))
            return v;
        return fallback;
    }

    protected string ArgsText(map<string, string> args)
    {
        string s = "";
        if (!args)
            return s;
        for (int i = 0; i < args.Count(); i++)
            s = s + " " + args.GetKey(i) + "=" + args.GetElement(i);
        return s;
    }

    PlayerBase FirstPlayer()
    {
        array<Man> men = new array<Man>();
        GetGame().GetPlayers(men);
        if (men.Count() == 0)
            return null;
        return PlayerBase.Cast(men.Get(0));
    }

    // "player" is the character itself; any other name is a handle.
    EntityAI ItemOf(PlayerBase player, string name)
    {
        if (name == "player")
            return player;
        EntityAI e;
        if (m_Handles.Find(name, e))
            return e;
        return null;
    }

    void RememberAs(string handle, EntityAI e)
    {
        if (handle == "" || !e)
            return;
        m_Handles.Set(handle, e);
    }

    protected void ForgetAll()
    {
        m_Handles.Clear();
    }

    void WatchItem(EntityAI e, string label)
    {
        if (!e)
            return;
        OZT_ProbeWatch w = new OZT_ProbeWatch();
        w.m_Item = e;
        w.m_Label = label;
        w.m_Last = OZT_ProbeInv.Where(e);
        w.m_StartedAt = GetGame().GetTickTime();
        w.m_CheckedAt = w.m_StartedAt;
        w.m_StartFrame = m_Frame;
        w.m_Seq = m_Seq;
        m_Watches.Insert(w);
        AddLine("watching " + label + " from " + w.m_Last);
    }

    void QueueLater(OZT_ProbeLater job)
    {
        job.m_Seq = m_Seq;
        m_Later.Insert(job);
    }

    // The cell an op means:
    //   free       the first place the occupancy map calls free for w x h
    //   taken      the top-left cell of the first item lying in that cargo
    //   last       the bottom-right cell of the grid
    //   <row>,<col> as given
    bool PickCell(EntityAI holder, string cellArg, int w, int h, EntityAI skip, out int row, out int col)
    {
        row = -1;
        col = -1;
        array<bool> taken;
        int gw;
        int gh;
        if (!OZT_ProbeInv.Map(holder, skip, taken, gw, gh))
            return false;
        if (cellArg == "free")
        {
            for (int r = 0; r < gh; r++)
            {
                for (int c = 0; c < gw; c++)
                {
                    if (OZT_ProbeInv.RectFree(taken, gw, gh, r, c, w, h))
                    {
                        row = r;
                        col = c;
                        return true;
                    }
                }
            }
            return false;
        }
        if (cellArg == "taken")
        {
            CargoBase cargo = holder.GetInventory().GetCargo();
            if (cargo.GetItemCount() == 0)
                return false;
            InventoryLocation il = new InventoryLocation();
            cargo.GetItem(0).GetInventory().GetCurrentInventoryLocation(il);
            row = il.GetRow();
            col = il.GetCol();
            return true;
        }
        if (cellArg == "last")
        {
            row = gh - 1;
            col = gw - 1;
            return true;
        }
        array<string> parts = new array<string>();
        cellArg.Split(",", parts);
        if (parts.Count() != 2)
            return false;
        row = parts.Get(0).ToInt();
        col = parts.Get(1).ToInt();
        return true;
    }

    // One creation at a named place, the way a deal would make a bought item.
    EntityAI MakeAt(PlayerBase player, int locType, EntityAI holder, string type, int row, int col, bool flip, int slot)
    {
        InventoryLocation loc = new InventoryLocation();
        if (locType == InventoryLocationType.HANDS)
        {
            if (!player)
                return null;
            loc.SetHands(player, null);
        }
        else
        {
            if (!holder)
                return null;
            if (locType == InventoryLocationType.ATTACHMENT)
                loc.SetAttachment(holder, null, slot);
            else
                loc.SetCargo(holder, null, 0, row, col, flip);
        }
        return GameInventory.LocationCreateEntity(loc, type, ECE_IN_INVENTORY, RF_DEFAULT);
    }

    // ---- every server frame -----------------------------------------------------

    void OnFrame()
    {
        m_Frame++;
        RunLater();
        RunWatches();
    }

    protected void RunLater()
    {
        for (int i = m_Later.Count() - 1; i >= 0; i--)
        {
            OZT_ProbeLater job = m_Later.Get(i);
            if (m_Frame < job.m_DueFrame)
                continue;
            m_Later.Remove(i);
            string line = "    later #" + job.m_Seq.ToString() + " frame=" + m_Frame.ToString() + " " + job.m_Kind + ": ";
            if (job.m_Kind == "delete")
            {
                line = line + OZT_ProbeInv.Name(job.m_Target);
                if (job.m_Target)
                    GetGame().ObjectDelete(job.m_Target);
            }
            else
            {
                EntityAI made = MakeAt(FirstPlayer(), job.m_LocType, job.m_Target, job.m_Class, job.m_Row, job.m_Col, job.m_Flip, job.m_Slot);
                line = line + job.m_Class + " -> " + OZT_ProbeInv.Where(made);
                if (made)
                {
                    RememberAs(job.m_Handle, made);
                    OZT_ProbeWatch w = new OZT_ProbeWatch();
                    w.m_Item = made;
                    w.m_Label = "made later " + job.m_Class;
                    w.m_Last = OZT_ProbeInv.Where(made);
                    w.m_StartedAt = GetGame().GetTickTime();
                    w.m_CheckedAt = w.m_StartedAt;
                    w.m_StartFrame = m_Frame;
                    w.m_Seq = job.m_Seq;
                    m_Watches.Insert(w);
                }
            }
            OZT_ProbeLog.Append(RESULTS, line);
        }
    }

    // An idle dedicated server runs thousands of frames a second. The first
    // fifty frames after an op are all looked at (that is where "same call" and
    // "next frame" are decided); after that ten looks a second are enough.
    protected void RunWatches()
    {
        if (m_Watches.Count() == 0)
            return;
        float now = GetGame().GetTickTime();
        for (int i = m_Watches.Count() - 1; i >= 0; i--)
        {
            OZT_ProbeWatch w = m_Watches.Get(i);
            int frames = m_Frame - w.m_StartFrame;
            float age = now - w.m_StartedAt;
            bool closing = age >= WATCH_SECONDS;
            if (!closing && frames > 50 && now - w.m_CheckedAt < 0.1)
                continue;
            w.m_CheckedAt = now;
            string spot = OZT_ProbeInv.Where(w.m_Item);
            if (w.m_Item && w.m_Item.IsPendingDeletion())
                spot = spot + " (pending deletion)";
            if (spot != w.m_Last || closing)
            {
                string tag = "changed";
                if (closing)
                    tag = "ends";
                string line = "    watch #" + w.m_Seq.ToString() + " " + w.m_Label + " " + tag;
                line = line + " +" + OZT_ProbeLog.R1(age * 1000) + " ms, " + frames.ToString() + " frames: " + spot;
                OZT_ProbeLog.Append(RESULTS, line);
                w.m_Last = spot;
            }
            if (closing || spot == "GONE")
                m_Watches.Remove(i);
        }
    }
}
```

```c
// The `ozt_probe` verb, following the bridge's own contract for project verbs
// (DZMCP_BridgeCore.c, "HOW A PROJECT ADDS ITS OWN VERB"): the name is added to
// KnownVerbs and IsKnownVerb and routed in Dispatch. Every op answers within
// its tick.
//
//   world_exec verb=ozt_probe args={"op":"status"}
//
// Every value of args is a string.
modded class DZMCP_BridgeCore
{
    override protected string KnownVerbs()
    {
        return super.KnownVerbs() + ", ozt_probe";
    }

    override protected bool IsKnownVerb(string verb)
    {
        if (verb == "ozt_probe")
            return true;
        return super.IsKnownVerb(verb);
    }

    override protected void Dispatch(string verb, string raw)
    {
        if (verb != "ozt_probe")
        {
            super.Dispatch(verb, raw);
            return;
        }

        DZMCP_CommandFull full = new DZMCP_CommandFull();
        string parseError;
        if (!m_Json.ReadFromString(full, raw, parseError))
        {
            FinishCommand(DZMCP_STATUS_FAILED, "ozt_probe: the args block could not be parsed -- every value must be a string: " + Excerpt(parseError));
            return;
        }

        map<string, string> args = full.args;
        string op = "status";
        string given;
        if (args && args.Find("op", given))
            op = given;

        string detail;
        if (OZT_Probe.Get().Command(op, args, detail))
            FinishCommand(DZMCP_STATUS_DONE, detail);
        else
            FinishCommand(DZMCP_STATUS_FAILED, detail);
    }
}
```

```c
// Stand only, client side. The stand writes
// $profile:OpenZone_TraderProbe/control.txt in the CLIENT's profile; the client
// reads its first line once a second, and a line it has not seen is a command:
//
//   dump <k>   the local player's inventory into client_dump.txt, in the format
//              of the server's server_dump.txt, and the command itself into
//              client_dump.ack so the reader knows which dump it holds.
class OZT_ProbeClient
{
    protected float  m_Timer;
    protected string m_Seen;

    void OZT_ProbeClient()
    {
        OZT_ProbeLog.EnsureDir();
    }

    void OnFrame(float timeslice)
    {
        m_Timer = m_Timer + timeslice;
        if (m_Timer < 1.0)
            return;
        m_Timer = 0;
        string path = OZT_ProbeLog.DIR + "/control.txt";
        if (!FileExist(path))
            return;
        FileHandle fh = OpenFile(path, FileMode.READ);
        if (fh == 0)
            return;
        string line;
        FGets(fh, line);
        CloseFile(fh);
        line = line.Trim();
        if (line == "" || line == m_Seen)
            return;
        m_Seen = line;
        if (line.IndexOf("dump") == 0)
            DumpInventory(line);
    }

    protected void DumpInventory(string command)
    {
        array<string> lines = new array<string>();
        PlayerBase player = PlayerBase.Cast(GetGame().GetPlayer());
        if (player)
            OZT_ProbeInv.Tree(player, lines);
        OZT_ProbeLog.WriteAll("client_dump.txt", lines);
        array<string> ack = new array<string>();
        ack.Insert(command + " items=" + lines.Count().ToString());
        OZT_ProbeLog.WriteAll("client_dump.ack", ack);
    }
}
```

```c
// Creation ops of the trader probe: one item made at a named place by a named
// engine call, with the place asked for and the place it ended in side by side.
class OZT_ProbeOpsCreate
{
    static bool MakeOne(OZT_Probe p, PlayerBase player, map<string, string> args, out string detail)
    {
        string type = p.ArgOf(args, "class", "");
        string intoName = p.ArgOf(args, "into", "player");
        string kind = p.ArgOf(args, "kind", "cargo");
        string via = p.ArgOf(args, "via", "loc");
        bool flip = p.ArgOf(args, "flip", "0") == "1";
        EntityAI into = p.ItemOf(player, intoName);
        if (type == "" || !into)
        {
            detail = "create needs class= and a known into= (player or a handle); got class='" + type + "' into='" + intoName + "'";
            return false;
        }

        int cw;
        int ch;
        bool sized = OZT_ProbeInv.ConfigSize(type, cw, ch);
        p.AddLine("config size of " + type + ": " + cw.ToString() + "x" + ch.ToString() + " found=" + OZT_ProbeLog.B(sized));
        if (!sized)
        {
            // no itemSize under the three roots: a cell is picked as for 1x1
            cw = 1;
            ch = 1;
        }

        EntityAI made;
        string asked = "";
        float t0 = GetGame().GetTickTime();
        if (kind == "hands")
            made = MakeInHands(player, type, via, asked);
        else if (kind == "slot")
            made = MakeInSlot(p, into, type, p.ArgOf(args, "slot", ""), via, asked);
        else
            made = MakeInCargo(p, into, type, p.ArgOf(args, "cell", "free"), flip, via, cw, ch, asked);
        float ms = (GetGame().GetTickTime() - t0) * 1000;

        if (!made)
        {
            detail = "create " + type + " asked " + asked + " -> the engine returned nothing";
            return true;
        }

        string qty = p.ArgOf(args, "qty", "");
        ItemBase ib = ItemBase.Cast(made);
        if (qty != "" && ib)
            ib.SetQuantity(qty.ToFloat());
        string ammo = p.ArgOf(args, "ammo", "");
        Magazine mag = Magazine.Cast(made);
        if (ammo != "" && mag)
            mag.ServerSetAmmoCount(ammo.ToInt());

        int ew;
        int eh;
        OZT_ProbeInv.SizeOf(made, ew, eh);
        p.RememberAs(p.ArgOf(args, "as", ""), made);
        p.WatchItem(made, "created " + type);
        detail = "create " + type + " asked " + asked + " -> got " + OZT_ProbeInv.Where(made);
        detail = detail + " | " + OZT_ProbeInv.Amount(made) + " | entity " + ew.ToString() + "x" + eh.ToString();
        detail = detail + " | " + OZT_ProbeLog.R1(ms) + " ms";
        return true;
    }

    protected static EntityAI MakeInCargo(OZT_Probe p, EntityAI into, string type, string cellArg, bool flip, string via, int cw, int ch, out string asked)
    {
        int w = cw;
        int h = ch;
        if (flip)
        {
            w = ch;
            h = cw;
        }
        int row;
        int col;
        if (!p.PickCell(into, cellArg, w, h, null, row, col))
        {
            asked = "cell=" + cellArg + " in " + into.GetType() + " (no such cell: no cargo, or nothing free by the map)";
            return null;
        }
        asked = "CARGO " + into.GetType() + " r" + row.ToString() + " c" + col.ToString();
        asked = asked + " flip=" + OZT_ProbeLog.B(flip) + " via=" + via;
        if (via == "ex")
            return into.GetInventory().CreateEntityInCargoEx(type, 0, row, col, flip);
        if (via == "find")
            return into.GetInventory().CreateEntityInCargo(type);
        InventoryLocation loc = new InventoryLocation();
        loc.SetCargo(into, null, 0, row, col, flip);
        return GameInventory.LocationCreateEntity(loc, type, ECE_IN_INVENTORY, RF_DEFAULT);
    }

    protected static EntityAI MakeInSlot(OZT_Probe p, EntityAI into, string type, string slotName, string via, out string asked)
    {
        if (via == "mag")
        {
            asked = "a magazine through Weapon_Base.SpawnAttachedMagazine on " + into.GetType();
            Weapon_Base wpn = Weapon_Base.Cast(into);
            if (!wpn)
                return null;
            return wpn.SpawnAttachedMagazine(type, WeaponWithAmmoFlags.NONE);
        }
        if (slotName == "")
        {
            asked = "ATT " + into.GetType() + " slot=(the engine's choice) via=CreateAttachment";
            return into.GetInventory().CreateAttachment(type);
        }
        asked = "ATT " + into.GetType() + " slot=" + slotName + " via=" + via;
        int slot = InventorySlots.GetSlotIdFromString(slotName);
        if (slot == InventorySlots.INVALID)
        {
            asked = asked + " (no slot has that name)";
            return null;
        }
        EntityAI there = into.GetInventory().FindAttachment(slot);
        if (there)
            p.AddLine("the slot " + slotName + " already holds " + OZT_ProbeInv.Name(there));
        if (via == "att")
            return into.GetInventory().CreateAttachmentEx(type, slot);
        InventoryLocation loc = new InventoryLocation();
        loc.SetAttachment(into, null, slot);
        return GameInventory.LocationCreateEntity(loc, type, ECE_IN_INVENTORY, RF_DEFAULT);
    }

    protected static EntityAI MakeInHands(PlayerBase player, string type, string via, out string asked)
    {
        EntityAI held = player.GetHumanInventory().GetEntityInHands();
        asked = "HANDS via=" + via + " (the hands hold " + OZT_ProbeInv.Name(held) + ")";
        if (via == "hands")
            return player.GetHumanInventory().CreateInHands(type);
        InventoryLocation loc = new InventoryLocation();
        loc.SetHands(player, null);
        return GameInventory.LocationCreateEntity(loc, type, ECE_IN_INVENTORY, RF_DEFAULT);
    }

    // A stack grown or shrunk by script, or a magazine's rounds set.
    static bool ChangeAmount(OZT_Probe p, PlayerBase player, map<string, string> args, out string detail)
    {
        EntityAI e = p.ItemOf(player, p.ArgOf(args, "item", ""));
        if (!e)
        {
            detail = "qty needs item=<handle of something that still exists>";
            return false;
        }
        string type = e.GetType();
        string before = OZT_ProbeInv.Amount(e);
        string setTo = p.ArgOf(args, "set", "");
        string add = p.ArgOf(args, "add", "");
        string ammo = p.ArgOf(args, "ammo", "");
        ItemBase ib = ItemBase.Cast(e);
        Magazine mag = Magazine.Cast(e);
        string call = "nothing: give set=, add= or ammo=";
        if (mag && ammo != "")
        {
            mag.ServerSetAmmoCount(ammo.ToInt());
            call = "ServerSetAmmoCount(" + ammo + ")";
        }
        else if (ib && setTo != "")
        {
            bool setOk = ib.SetQuantity(setTo.ToFloat());
            call = "SetQuantity(" + setTo + ") answered " + OZT_ProbeLog.B(setOk);
        }
        else if (ib && add != "")
        {
            bool addOk = ib.AddQuantity(add.ToFloat());
            call = "AddQuantity(" + add + ") answered " + OZT_ProbeLog.B(addOk);
        }
        string after = "GONE in the same call";
        if (e)
            after = OZT_ProbeInv.Amount(e);
        if (e && ib)
        {
            string caps = "GetQuantityMax=" + ib.GetQuantityMax().ToString() + " GetTargetQuantityMax=" + ib.GetTargetQuantityMax(-1).ToString();
            caps = caps + " varStackMax=" + ib.ConfigGetInt("varStackMax").ToString() + " CanBeSplit=" + OZT_ProbeLog.B(ib.CanBeSplit());
            caps = caps + " IsFullQuantity=" + OZT_ProbeLog.B(ib.IsFullQuantity());
            p.AddLine(caps);
        }
        // a stack set to zero may already read null here; WatchItem takes that
        p.WatchItem(e, "amount of " + type);
        detail = type + ": " + before + " -> " + call + " -> " + after;
        return true;
    }
}
```

```c
// What the engine and the scripts answer BEFORE anything is created or moved.
// Task 4 needs the state of the hands; Task 7 adds the gates asked with a probe
// entity.
class OZT_ProbeOpsGate
{
    // Everything that decides whether the hands can take an item now, and
    // whether a deal may touch the inventory at all. PlayerBase.CanDeleteItems
    // is vanilla's own "the player is doing nothing with their things".
    static bool HandsState(OZT_Probe p, PlayerBase player, out string detail)
    {
        EntityAI held = player.GetHumanInventory().GetEntityInHands();
        bool acting = false;
        if (player.GetActionManager() && player.GetActionManager().GetRunningAction())
            acting = true;
        detail = "hands hold " + OZT_ProbeInv.Name(held);
        detail = detail + " | inventory processing=" + OZT_ProbeLog.B(player.GetDayZPlayerInventory().IsProcessing());
        detail = detail + " | CanDeleteItems=" + OZT_ProbeLog.B(player.CanDeleteItems());
        detail = detail + " | action running=" + OZT_ProbeLog.B(acting);
        detail = detail + " | in vehicle=" + OZT_ProbeLog.B(player.IsInVehicle());
        string body = "alive=" + OZT_ProbeLog.B(player.IsAlive()) + " unconscious=" + OZT_ProbeLog.B(player.IsUnconscious());
        body = body + " restrained=" + OZT_ProbeLog.B(player.IsRestrained());
        p.AddLine(body);
        if (held)
            p.AddLine("juncture on the held item=" + OZT_ProbeLog.B(GetGame().HasInventoryJunctureItem(held)));
        return true;
    }
}
```

```c
// The deletion op of the trader probe. A deal deletes what is sold and then
// creates what is bought; the question is whether the second may use the room
// of the first within one script call, and how each way of deleting behaves.
class OZT_ProbeOpsDelete
{
    static bool DeleteOne(OZT_Probe p, PlayerBase player, map<string, string> args, out string detail)
    {
        EntityAI e = p.ItemOf(player, p.ArgOf(args, "item", ""));
        if (!e || e == player)
        {
            detail = "del needs item=<handle of something that still exists>";
            return false;
        }
        string how = p.ArgOf(args, "how", "object");
        string follow = p.ArgOf(args, "follow", "none");
        string type = p.ArgOf(args, "class", e.GetType());
        string handle = p.ArgOf(args, "as", "");

        // the place that is about to be freed
        InventoryLocation was = new InventoryLocation();
        e.GetInventory().GetCurrentInventoryLocation(was);
        EntityAI holder = was.GetParent();
        int lt = was.GetType();
        int row = was.GetRow();
        int col = was.GetCol();
        int slot = was.GetSlot();
        bool flip = was.GetFlip();
        string place = OZT_ProbeInv.Where(e);
        int before = ItemsIn(holder);

        // what hangs on it goes with it; watch when
        int kids = e.GetInventory().AttachmentCount();
        for (int k = 0; k < kids; k++)
            p.WatchItem(e.GetInventory().GetAttachmentFromIndex(k), "part of the doomed " + e.GetType());
        p.WatchItem(e, "doomed " + e.GetType());

        if (how == "delete")
            e.Delete();
        else if (how == "safe")
            e.DeleteSafe();
        else
            GetGame().ObjectDelete(e);

        // the same script call, right after
        string state = "the reference reads null";
        if (e)
        {
            state = "still there: pending=" + OZT_ProbeLog.B(e.IsPendingDeletion()) + " toDelete=" + OZT_ProbeLog.B(e.ToDelete());
            state = state + " setForDeletion=" + OZT_ProbeLog.B(e.IsSetForDeletion()) + " at " + OZT_ProbeInv.Where(e);
        }
        p.AddLine("deleted by " + how + " from " + place + "; same call: " + state);
        p.AddLine("items in the holder's cargo: " + before.ToString() + " before, " + ItemsIn(holder).ToString() + " in the same call");
        detail = "del " + how + " " + place + " | same call: " + state;

        if (follow == "none")
            return true;

        if (follow == "can")
        {
            if (lt != InventoryLocationType.CARGO || !holder)
            {
                p.AddLine("follow=can only asks about a cargo cell");
                return true;
            }
            EntityAI probe = EntityAI.Cast(GetGame().CreateObjectEx(type, player.GetPosition(), ECE_LOCAL));
            if (!probe)
            {
                p.AddLine("no local probe entity of class " + type);
                return true;
            }
            InventoryLocation loc = new InventoryLocation();
            loc.SetCargo(holder, probe, 0, row, col, flip);
            bool canAdd = GameInventory.LocationCanAddEntity(loc);
            bool occFree = holder.GetInventory().TestAddEntityInCargoEx(probe, 0, row, col, flip, false, false, false, true, false, false);
            GetGame().ObjectDelete(probe);
            string asked = "the freed cell in the same call: LocationCanAddEntity=" + OZT_ProbeLog.B(canAdd);
            asked = asked + " occupancy test alone=" + OZT_ProbeLog.B(occFree);
            p.AddLine(asked);
            detail = detail + " | " + asked;
            return true;
        }

        if (follow == "next")
        {
            OZT_ProbeLater job = new OZT_ProbeLater();
            job.m_DueFrame = p.FrameNo() + p.ArgOf(args, "frames", "1").ToInt();
            job.m_Kind = "create";
            job.m_Class = type;
            job.m_Handle = handle;
            job.m_Target = holder;
            job.m_LocType = lt;
            job.m_Row = row;
            job.m_Col = col;
            job.m_Slot = slot;
            job.m_Flip = flip;
            p.QueueLater(job);
            detail = detail + " | " + type + " queued for frame " + job.m_DueFrame.ToString() + " (now " + p.FrameNo().ToString() + ")";
            return true;
        }

        // follow=create: the same call
        EntityAI made = p.MakeAt(player, lt, holder, type, row, col, flip, slot);
        string got = "the engine returned nothing";
        if (made)
        {
            got = OZT_ProbeInv.Where(made);
            p.RememberAs(handle, made);
            p.WatchItem(made, "made in the freed place " + type);
        }
        p.AddLine("same call: " + type + " created at the freed place -> " + got);
        detail = detail + " | same-call create -> " + got;
        return true;
    }

    protected static int ItemsIn(EntityAI holder)
    {
        if (!holder || !holder.GetInventory())
            return -1;
        CargoBase cargo = holder.GetInventory().GetCargo();
        if (!cargo)
            return -1;
        return cargo.GetItemCount();
    }
}
```

```c
// Move ops of the trader probe. A part the player keeps comes off the sold
// item and goes to a planned cell: by which server call, when does it land,
// what do the script gates say and does the call obey them, and what happens
// when the item it sat on is deleted right after.
class OZT_ProbeOpsMove
{
    static bool MoveOne(OZT_Probe p, PlayerBase player, map<string, string> args, out string detail)
    {
        EntityAI e = p.ItemOf(player, p.ArgOf(args, "item", ""));
        if (!e || e == player)
        {
            detail = "move needs item=<handle of something that still exists>";
            return false;
        }
        InventoryLocation src = new InventoryLocation();
        e.GetInventory().GetCurrentInventoryLocation(src);
        EntityAI host = src.GetParent();
        string from = OZT_ProbeInv.Where(e);
        string follow = p.ArgOf(args, "follow", "none");

        if (p.ArgOf(args, "kind", "cargo") == "hands")
        {
            p.AddLine("from " + from + "; source gates: " + SourceGates(e, host, src.GetType()));
            p.WatchItem(e, "to the hands " + e.GetType());
            player.ServerTakeEntityToHands(e);
            detail = "move " + e.GetType() + " to the hands by ServerTakeEntityToHands; same call: " + OZT_ProbeInv.Where(e);
            return true;
        }

        EntityAI into = p.ItemOf(player, p.ArgOf(args, "into", ""));
        if (!into)
        {
            detail = "move needs into=<handle of a container>";
            return false;
        }
        string via = p.ArgOf(args, "via", "dst");
        bool flip = p.ArgOf(args, "flip", "0") == "1";
        int w;
        int h;
        OZT_ProbeInv.SizeOf(e, w, h);
        if (flip)
        {
            int turned = w;
            w = h;
            h = turned;
        }
        int row;
        int col;
        if (!p.PickCell(into, p.ArgOf(args, "cell", "free"), w, h, e, row, col))
        {
            detail = "move: no such cell in " + into.GetType() + " for " + w.ToString() + "x" + h.ToString();
            return true;
        }
        InventoryLocation dst = new InventoryLocation();
        dst.SetCargo(into, e, 0, row, col, flip);

        // what the scripts and the engine say before anything moves
        string gates = SourceGates(e, host, src.GetType());
        gates = gates + " | item.CanPutInCargo=" + OZT_ProbeLog.B(e.CanPutInCargo(into));
        gates = gates + " into.CanReceiveItemIntoCargo=" + OZT_ProbeLog.B(into.CanReceiveItemIntoCargo(e));
        gates = gates + " into children accessible=" + OZT_ProbeLog.B(into.GetInventory().AreChildrenAccessible());
        bool engineOk = GameInventory.LocationCanAddEntity(dst);
        string target = "CARGO " + into.GetType() + " r" + row.ToString() + " c" + col.ToString() + " flip=" + OZT_ProbeLog.B(flip);
        p.AddLine("from " + from + " to " + target + " via=" + via);
        p.AddLine("gates: " + gates);
        p.AddLine("LocationCanAddEntity(destination)=" + OZT_ProbeLog.B(engineOk));

        // Never hand the engine a destination it refused: that has ended the
        // server process without a log.
        if (!engineOk)
        {
            detail = "move NOT attempted: LocationCanAddEntity refused " + target + " | " + gates;
            return true;
        }

        p.WatchItem(e, "moved " + e.GetType());
        bool answered;
        float t0 = GetGame().GetTickTime();
        if (via == "cargoex")
            answered = player.ServerTakeEntityToTargetCargoEx(into.GetInventory().GetCargo(), e, row, col);
        else
            answered = player.ServerTakeToDst(src, dst);
        float ms = (GetGame().GetTickTime() - t0) * 1000;
        string sameCall = OZT_ProbeInv.Where(e);
        p.AddLine("the call answered " + OZT_ProbeLog.B(answered) + " in " + OZT_ProbeLog.R1(ms) + " ms; same call the item reads: " + sameCall);

        Weapon_Base wpn = Weapon_Base.Cast(host);
        if (wpn)
        {
            Magazine still = wpn.GetMagazine(wpn.GetCurrentMuzzle());
            p.AddLine("the weapon in the same call: GetMagazine=" + OZT_ProbeInv.Name(still) + " IsIdle=" + OZT_ProbeLog.B(wpn.IsIdle()));
        }

        detail = "move " + e.GetType() + " " + via + " answered " + OZT_ProbeLog.B(answered) + " | same call: " + sameCall;
        detail = detail + " | " + gates;

        // The order of a deal's commit: kept parts move, then what was sold is
        // deleted. Does the part outlive the item it sat on?
        if (follow == "delhost" && host && host != player)
        {
            p.WatchItem(host, "host of the kept part " + host.GetType());
            GetGame().ObjectDelete(host);
            p.AddLine("the host " + host.GetType() + " deleted in the same call; the part now reads: " + OZT_ProbeInv.Where(e));
        }
        if (follow == "delhost_next" && host && host != player)
        {
            OZT_ProbeLater job = new OZT_ProbeLater();
            job.m_DueFrame = p.FrameNo() + 1;
            job.m_Kind = "delete";
            job.m_Target = host;
            p.QueueLater(job);
            p.WatchItem(host, "host of the kept part " + host.GetType());
            p.AddLine("the host " + host.GetType() + " queued for deletion on frame " + job.m_DueFrame.ToString());
        }
        return true;
    }

    // What the item's present holder says about letting it go.
    protected static string SourceGates(EntityAI e, EntityAI host, int srcType)
    {
        if (!host)
            return "no host";
        string s = "host " + host.GetType() + " children accessible=" + OZT_ProbeLog.B(host.GetInventory().AreChildrenAccessible());
        if (srcType == InventoryLocationType.ATTACHMENT)
            s = s + " host.CanReleaseAttachment=" + OZT_ProbeLog.B(host.CanReleaseAttachment(e));
        if (srcType == InventoryLocationType.CARGO)
        {
            s = s + " host.CanReleaseCargo=" + OZT_ProbeLog.B(host.CanReleaseCargo(e));
            s = s + " item.CanRemoveFromCargo=" + OZT_ProbeLog.B(e.CanRemoveFromCargo(host));
        }
        return s;
    }

    // The fallback for a part that will not move: delete it and create the same
    // class at the planned cell with its amount and health. What another mod
    // stored on the item is lost this way, which is why it is the fallback.
    static bool RecreateOne(OZT_Probe p, PlayerBase player, map<string, string> args, out string detail)
    {
        EntityAI e = p.ItemOf(player, p.ArgOf(args, "item", ""));
        EntityAI into = p.ItemOf(player, p.ArgOf(args, "into", ""));
        if (!e || e == player || !into)
        {
            detail = "recreate needs item=<handle> and into=<handle of a container>";
            return false;
        }
        bool flip = p.ArgOf(args, "flip", "0") == "1";
        string type = e.GetType();
        int w;
        int h;
        OZT_ProbeInv.SizeOf(e, w, h);
        if (flip)
        {
            int turned = w;
            w = h;
            h = turned;
        }
        int row;
        int col;
        if (!p.PickCell(into, p.ArgOf(args, "cell", "free"), w, h, e, row, col))
        {
            detail = "recreate: no such cell in " + into.GetType();
            return true;
        }

        string from = OZT_ProbeInv.Where(e);
        string amount = OZT_ProbeInv.Amount(e);
        float health = e.GetHealth01("", "");
        int rounds = -1;
        float quantity = -1;
        Magazine oldMag = Magazine.Cast(e);
        ItemBase oldItem = ItemBase.Cast(e);
        if (oldMag)
            rounds = oldMag.GetAmmoCount();
        else if (oldItem && oldItem.HasQuantity())
            quantity = oldItem.GetQuantity();

        p.WatchItem(e, "old " + type);
        GetGame().ObjectDelete(e);

        InventoryLocation loc = new InventoryLocation();
        loc.SetCargo(into, null, 0, row, col, flip);
        EntityAI made = GameInventory.LocationCreateEntity(loc, type, ECE_IN_INVENTORY, RF_DEFAULT);
        if (!made)
        {
            detail = "recreate " + type + ": the old one is deleted and the engine created nothing at the cell";
            return true;
        }
        made.SetHealth01("", "", health);
        Magazine newMag = Magazine.Cast(made);
        ItemBase newItem = ItemBase.Cast(made);
        if (newMag && rounds >= 0)
            newMag.ServerSetAmmoCount(rounds);
        else if (newItem && quantity >= 0)
            newItem.SetQuantity(quantity);
        p.RememberAs(p.ArgOf(args, "as", ""), made);
        p.WatchItem(made, "new " + type);
        detail = "recreate " + type + " from " + from + " (" + amount + ") -> " + OZT_ProbeInv.Where(made);
        detail = detail + " (" + OZT_ProbeInv.Amount(made) + ", health " + OZT_ProbeLog.R1(made.GetHealth01("", "") * 100) + "%)";
        return true;
    }
}
```

```c
    static bool AskGates(OZT_Probe p, PlayerBase player, map<string, string> args, out string detail)
    {
        string type = p.ArgOf(args, "class", "Paper");
        string kind = p.ArgOf(args, "kind", "cargo");

        float t0 = GetGame().GetTickTime();
```
