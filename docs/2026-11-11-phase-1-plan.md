# OpenZone Trader, Phase 1: The Server Half for Plain Items — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the server half of `OpenZone_Trader` for plain items (configs, the price book, item money, the inventory model, the service operations `open` and `deal`, an object trader from JSON) and prove it with scripted deals through the stand bridge: paid, short of money, change in notes, one overflow to the hands, two overflows refused, price changed.

No screen yet: a stand-only pbo, `OpenZone_Trader_Bridge`, adds the verb `oz_trader`, which sends the same requests a client will send, through the same service handler.

**Tech Stack:** Enforce Script on DayZ 1.30.164289 (diag build), CF, `OpenZone_Core` (config loader, service registry, log), the `dayz` MCP server, the phase 0 probe as the stand's scene builder, git.

## What phase 0 settled, in the words the code uses

- A place that is not free, or that a script gate refuses, makes `LocationCreateEntity` return null and creates nothing anywhere.
- `ObjectDelete` takes an item out of its place at once; the next line may create there.
- The plan's own occupancy map (each item's own inventory location, never `CargoBase.GetItemRowCol`) agrees with the engine on every cell.
- A script gate is asked with a local entity of the class (`CreateObjectEx(type, pos, ECE_LOCAL)`, deleted in the same call) through `TestAddEntityInCargoEx(probe, 0, row, col, flip, false, true, false, false, true, false)`; the answer does not depend on the cell.
- `SetQuantity` and `AddQuantity` return "the item was destroyed", not "it worked"; a number above the maximum is clamped without a word; an ammunition pile set to zero stays.
- A holder takes what its own gate takes, at any depth; `AreChildrenAccessible` is not asked.
- The hands are free when `HumanInventory.CanAddEntityInHands(probe)` says yes; a deal starts only when `PlayerBase.CanDeleteItems()` is true, the inventory is not processing and no action runs.

## Decisions this plan makes where the design is silent

The owner should see these; each is one constant or one short function, easy to change.

1. **JSON keys.** `ClassName`, not `Class` (an engine type name cannot be a field); a trader's money provider is `Provider`, not `Money`. Task 8 corrects the two examples in the design.
2. **A price of 0 or less turns that side off.** An absent key reads 0, so "no `Sell`" means "the trader does not take it". The design's `-1` still works.
3. **One class, one entry.** A class may stand in the price book once; a second entry is dropped with a warning. Goods are named by class on the wire.
4. **Notes.** Every note's value is a multiple of the smallest note's; one that is not is dropped with a warning (greedy change is then always exact). A note is an ordinary quantity stack: an ammunition class is refused as a note.
5. **Rounding.** A line's price is rounded to the smallest note, half up; with a provider that is not items the unit is 1.
6. **A request that names goods the trader does not sell** (a stale catalogue) is refused as `changed`.
7. **Merging.** Bought stackable goods and notes are added to a stack of the same class that is not ruined, wherever it lies, up to its maximum; the rest becomes new stacks.
8. **Decision 4 is a switch.** `WearBought` in the settings (default 1): a bought item that fits a free slot of the character is created on it. 0 sends everything to the bags.
9. **`busy`** covers both "the last deal was less than `CooldownMs` ago" and "the player is doing something with their things". `CooldownMs` is 0 to 600000 (ten minutes); the cooldown counts from the player's last deal that stood.
10. **The order of containers** a new item tries: the order the engine enumerates the character's inventory in (clothing first, then what hangs on it, then what lies inside), note holders first for notes.
11. **The order of things.** A deal lays several things at once and each takes the first place that fits, so the order decides what fits. Bought lines are laid largest footprint first (lines of one size in the order asked), then the notes of change or payout: small things fill what large ones leave. If more than one thing is then left without a place, everything is laid once more with the first thing that needs cells, the largest, set aside for the hands; if that leaves nothing without a place, the deal stands with that thing in the hands. The count a refusal carries is the first laying's. The plan never moves a thing the player already carries, and it tries these two layings, not every arrangement: a set that only a cleverer packing would fit is refused, and the player buys it in two deals.
12. **`problems=`** in the ready line and in the answer of a reload counts every WARNING line of that load: a value out of range that `Validate` fixed (the core's loader then writes the fix back to the file) as well as a cross-check (which changes memory only and never the file).

- [ ] **Step 4: Write `tools/stringtable.py`**

```python
# Expands <mod>/strings.csv (key, Ukrainian, English) into the game's
# <mod>/stringtable.csv: fifteen columns, every field quoted, a comma after the
# last one, a BOM in front -- the shape the rest of the series ships. Ukrainian
# is the original and stands in every column but the English one.
#
# Usage: python -I tools/stringtable.py <path to the mod's folder>
import csv
import io
import os
import sys

COLUMNS = ["Language", "original", "english", "czech", "german", "russian", "polish",
           "hungarian", "italian", "spanish", "french", "chinese", "japanese",
           "portuguese", "chinesesimp"]

mod = sys.argv[1]
rows = []
with io.open(os.path.join(mod, "strings.csv"), encoding="utf-8-sig", newline="") as f:
    for line in csv.reader(f):
        if not line or line[0].startswith("#"):
            continue
        if len(line) != 3:
            raise SystemExit("strings.csv: three fields a line, got %r" % (line,))
        key, ukrainian, english = line
        row = [key, ukrainian, english] + [ukrainian] * (len(COLUMNS) - 3)
        rows.append(row)

keys = [r[0] for r in rows]
twice = sorted(set(k for k in keys if keys.count(k) > 1))
if twice:
    raise SystemExit("strings.csv: listed twice: %s" % ", ".join(twice))


def quoted(fields):
    return ",".join('"' + x.replace('"', '""') + '"' for x in fields) + ","


text = "\n".join([quoted(COLUMNS)] + [quoted(r) for r in rows]) + "\n"
with io.open(os.path.join(mod, "stringtable.csv"), "w", encoding="utf-8-sig", newline="\n") as f:
    f.write(text)
print("stringtable.csv: %d strings" % len(rows))
```

```c
// Ids the admin types (a category, a trader) become keys, log words and, later,
// file names: letters, digits, `_` and `-`, at most 64.
class OZT_Ids
{
    static bool IsSafe(string id)
    {
        int n = id.Length();
        if (n == 0 || n > 64)
            return false;

        for (int i = 0; i < n; i++)
        {
            int c = id.Get(i).ToAscii();
            bool digit = c >= 48 && c <= 57;
            bool upper = c >= 65 && c <= 90;
            bool lower = c >= 97 && c <= 122;
            bool punct = c == 95 || c == 45;
            if (!digit && !upper && !lower && !punct)
                return false;
        }
        return true;
    }
}
```

```c
// What the trader pays for an item that is not pristine, as a share of the
// pristine price. A ruined item is not taken at all.
class OZT_ConditionFactors
{
    float Pristine = 1;
    float Worn = 0.85;
    float Damaged = 0.6;
    float BadlyDamaged = 0.35;

    OZT_ConditionFactors Copy()
    {
        OZT_ConditionFactors c = new OZT_ConditionFactors();
        c.Pristine = Pristine;
        c.Worn = Worn;
        c.Damaged = Damaged;
        c.BadlyDamaged = BadlyDamaged;
        return c;

    float Of(int level)
    {
        if (level <= 0)
            return Pristine;
        if (level == 1)
            return Worn;
        if (level == 2)
            return Damaged;
        if (level == 3)
            return BadlyDamaged;
        return 0;

class OZT_Settings : OZ_ConfigBase
{
    string Provider = "items";
    ref array<ref OZT_Note> Notes;
    ref array<string> Holders;
    ref OZT_ConditionFactors Condition;

    // The least time between two deals of one player, in milliseconds.
    int CooldownMs = 1000;

    // 1: a bought item that fits a free slot of the character is created on it
    // (decision 4 of the design); 0: everything goes to the bags.
    int WearBought = 1;

    override int LatestVersion()
    {
        return 1;
    }

    override void LoadDefaults()
    {
        super.LoadDefaults();
        Provider = OZT_Const.PROVIDER_ITEMS;
        Notes = new array<ref OZT_Note>();
        Holders = new array<string>();
        Condition = new OZT_ConditionFactors();
        CooldownMs = 1000;
        WearBought = 1;
    }

    override void Validate(out int warnings)
    {
        warnings = 0;

        if (Provider == "")
            Provider = OZT_Const.PROVIDER_ITEMS;

        // Everything nested goes into objects a script made (OZ_ConfigBase.c):
        // what the loader allocated ran no field initialiser.
        array<ref OZT_Note> notes = new array<ref OZT_Note>();
        if (Notes)
        {
            for (int i = 0; i < Notes.Count(); i++)
            {
                OZT_Note n = Notes[i];
                if (n)
                    notes.Insert(n.Copy());
            }
        }
        Notes = notes;

        array<string> holders = new array<string>();
        if (Holders)
        {
            for (int h = 0; h < Holders.Count(); h++)
            {
                if (Holders[h] != "")
                    holders.Insert(Holders[h]);
            }
        }
        Holders = holders;

        if (!Condition)
            Condition = new OZT_ConditionFactors();
        else
            Condition = Condition.Copy();

        // An absent section comes back allocated and zeroed, and the copy
        // carries those zeros: four zeros mean "the file did not say".
        float sum = Condition.Pristine + Condition.Worn + Condition.Damaged + Condition.BadlyDamaged;
        if (sum <= 0)
            Condition = new OZT_ConditionFactors();

        bool negative = Condition.Pristine < 0 || Condition.Worn < 0;
        if (Condition.Damaged < 0 || Condition.BadlyDamaged < 0)
            negative = true;
        if (negative)
        {
            OZT_Log.Warn("Settings: a condition factor is below zero, using the defaults");
            Condition = new OZT_ConditionFactors();
            warnings++;
        }

        if (CooldownMs < 0 || CooldownMs > 600000)
        {
            OZT_Log.Warn("Settings: CooldownMs " + CooldownMs.ToString() + " is outside 0..600000, using 1000");
            CooldownMs = 1000;
            warnings++;
        }
```

```c
            lines.Insert(e);
```

```c
// The three files of the trader, live: loaded with the core's loader, then
// checked against the game's config and against each other.
//
// The cross-checks change the objects IN MEMORY only. The loader writes a
// Validate fix back to the admin's file, and "a mod was not loaded today" or
// "the notes changed" must not delete or rewrite a line of it.
//
// Every finding of a load is a WARNING line and counts in `problems=` of the
// ready line, whichever of the two it is: a Validate fix (a value out of range,
// which the loader then writes back) or a cross-check.
class OZT_Config
{
    private static ref OZT_Config s_Instance;

    private ref OZT_Settings    m_Settings;
    private ref OZT_GoodsFile   m_Goods;
    private ref OZT_TradersFile m_Traders;
    private int m_Revision;
    private int m_Problems;
    private int m_GoodsCount;

    static OZT_Config Get()
    {
        if (!s_Instance)
            s_Instance = new OZT_Config();
        return s_Instance;
    }

    static void ServerLoad()
    {
        Get().LoadAll();
    }

    OZT_Settings Settings()
    {
        return m_Settings;
    }

    OZT_GoodsFile Goods()
    {
        return m_Goods;
    }

    OZT_TradersFile Traders()
    {
        return m_Traders;
    }

    // unchanged catalogue can later be skipped.
    int Revision()
    {
        return m_Revision;
    }

    // The smallest amount that can change hands: the smallest note's value with
    // item money, 1 with any other provider.
    int Unit()
    {
        if (m_Settings.Provider != OZT_Const.PROVIDER_ITEMS)
            return 1;
        if (m_Settings.Notes.Count() == 0)
            return 1;
        return m_Settings.Notes[0].Value;

    {
        OZT_Log.Warn(msg);

    // Notes: a real quantity item, worth something, listed once; ascending by
    // value; every value a multiple of the smallest, so that change made from
    // the largest note downward always comes out exact.
    private void CheckNotes()
    {
        array<ref OZT_Note> kept = new array<ref OZT_Note>();
        for (int i = 0; i < m_Settings.Notes.Count(); i++)
        {
            OZT_Note n = m_Settings.Notes[i];
            string why = "";
            if (n.Value <= 0)
                why = "its Value is not above zero";
            else if (!ClassKnown(n.ClassName))
                why = "no such class";
            else if (GetGame().ConfigIsExisting("CfgMagazines " + n.ClassName))
                why = "ammunition counts rounds, not quantity, and cannot be a note";
            else if (NoteIn(kept, n.ClassName))
                why = "it is listed twice";
            if (why != "")
            {
                Problem("Settings: the note '" + n.ClassName + "' is dropped: " + why);
                continue;
            }
            int at = 0;
            while (at < kept.Count() && kept[at].Value <= n.Value)
                at++;
            kept.InsertAt(n, at);
        }

        for (int k = kept.Count() - 1; k >= 1; k--)
        {
            if (kept[k].Value % kept[0].Value == 0)
                continue;
            string odd = "Settings: the note '" + kept[k].ClassName + "' is dropped: its value " + kept[k].Value.ToString();
            odd = odd + " is not a multiple of the smallest note's " + kept[0].Value.ToString();
            Problem(odd);
            kept.RemoveOrdered(k);
        }
        m_Settings.Notes = kept;

        if (m_Settings.Provider == OZT_Const.PROVIDER_ITEMS && kept.Count() == 0)
            OZT_Log.Info("Settings: item money with no notes configured: nothing can be paid or paid out until Notes names some");
    }

    private bool NoteIn(array<ref OZT_Note> notes, string type)
    {
        for (int i = 0; i < notes.Count(); i++)
        {
            if (notes[i].ClassName == type)
                return true;
        }
        return false;
    }

    // Goods: the class exists, stands in the book once, and both prices are
    // whole multiples of the smallest note.
    private void CheckGoods()
    {
        int unit = Unit();
        array<string> seen = new array<string>();
        m_GoodsCount = 0;
        for (int c = 0; c < m_Goods.Categories.Count(); c++)
        {
            OZT_Category cat = m_Goods.Categories[c];
            array<ref OZT_Goods> kept = new array<ref OZT_Goods>();
            for (int g = 0; g < cat.Goods.Count(); g++)
            {
                OZT_Goods e = cat.Goods[g];
                if (!ClassKnown(e.ClassName))
                {
                    Problem("Goods: '" + e.ClassName + "' in category '" + cat.Id + "' is skipped: no such class");
                    continue;
                }
                if (seen.Find(e.ClassName) > -1)
                {
                    Problem("Goods: '" + e.ClassName + "' in category '" + cat.Id + "' is skipped: the class is in the price book already");
                    continue;
                }
                seen.Insert(e.ClassName);
                e.Buy = Fitted(e.ClassName, "Buy", e.Buy, unit);
                e.Sell = Fitted(e.ClassName, "Sell", e.Sell, unit);
                kept.Insert(e);
            }
            cat.Goods = kept;
            m_GoodsCount = m_GoodsCount + kept.Count();
        }
    }

    private int Fitted(string type, string side, int price, int unit)
    {
        if (price <= 0 || unit <= 1)
            return price;
        if (price % unit == 0)
            return price;
        int rounded = RoundTo(price, unit);
        string msg = "Goods: " + side + " of '" + type + "' is " + price.ToString();
        msg = msg + ", not a multiple of the smallest note (" + unit.ToString() + "); using " + rounded.ToString();
        Problem(msg);
        return rounded;
    }

    // Points: this phase stands objects only; the class exists; the categories
    // a point names are in the book.
    private void CheckTraders()
    {
        array<ref OZT_Point> kept = new array<ref OZT_Point>();
        for (int i = 0; i < m_Traders.Traders.Count(); i++)
        {
            OZT_Point p = m_Traders.Traders[i];
            if (p.Kind == OZT_Const.KIND_NPC)
            {
                Problem("Traders: '" + p.Id + "' is an npc; the NPC is not built yet, the point is skipped");
                continue;
            }
            if (!ClassKnown(p.ClassName))
            {
                Problem("Traders: '" + p.Id + "' is skipped: no such class '" + p.ClassName + "'");
                continue;
            }
            array<string> cats = new array<string>();
            for (int c = 0; c < p.Categories.Count(); c++)
            {
                string id = p.Categories[c];
                if (FindCategory(id))
                    cats.Insert(id);
                else
                    Problem("Traders: '" + p.Id + "' names the category '" + id + "', which the price book does not have");
            }
            p.Categories = cats;
            kept.Insert(p);
        }
        m_Traders.Traders = kept;
    }
}
```

```c
// The price book at run time, and how a deal counts "how much of it".

// A stack is counted in units when the engine lets it be split: a pile of nails,
// a wad of notes, a pile of rounds. A canteen has a quantity too, but that is
// what is left in it, not a number of things.
class OZT_Stack
{
    static bool Countable(EntityAI e)
    {
        Magazine mag = Magazine.Cast(e);
        if (mag)
            return mag.IsAmmoPile();
        ItemBase ib = ItemBase.Cast(e);
        if (!ib)
            return false;
        return ib.HasQuantity() && ib.IsSplitable();
    }

    static int Units(EntityAI e)
    {
        if (!Countable(e))
            return 1;
        Magazine mag = Magazine.Cast(e);
        if (mag)
            return mag.GetAmmoCount();
        ItemBase ib = ItemBase.Cast(e);
        int n = ib.GetQuantity();
        return n;
    }

    // The most one stack of this thing holds where it lies in a cargo.
    static int Max(EntityAI e)
    {
        if (!Countable(e))
            return 1;
        Magazine mag = Magazine.Cast(e);
        if (mag)
            return mag.GetAmmoMax();
        ItemBase ib = ItemBase.Cast(e);
        return ib.GetTargetQuantityMax(-1);
    }

    // Measured in phase 0: the bool these engine calls return means "the item
    // was destroyed", so it is not read; and a pile's rounds are its amount.
    // AddQuantity with both destroy flags off never deletes the stack: a stack
    // the deal empties is deleted by the deal, with ObjectDelete.
    static void Add(EntityAI e, int units)
    {
        Magazine mag = Magazine.Cast(e);
        if (mag)
        {
            mag.ServerSetAmmoCount(mag.GetAmmoCount() + units);
            return;
        }
        ItemBase ib = ItemBase.Cast(e);
        if (ib)
            ib.AddQuantity(units, false, false);
    }

    static void Set(EntityAI e, int units)
    {
        Magazine mag = Magazine.Cast(e);
        if (mag)
        {
            mag.ServerSetAmmoCount(units);
            return;
        }
        ItemBase ib = ItemBase.Cast(e);
        if (ib)
            ib.SetQuantity(units);
    }

    // What is left of a thing that is used up, 0..1; 1 for anything that has no
    // such notion.
    static float Fraction(EntityAI e)
    {
        ItemBase ib = ItemBase.Cast(e);
        if (!ib || !ib.HasQuantity())
            return 1;
        if (Magazine.Cast(e))
            return 1;
        float most = ib.GetQuantityMax();
        if (most <= 0)
            return 1;
        float part = ib.GetQuantity() / most;
        return Math.Clamp(part, 0, 1);
    }
}

{

    string Category;

    int Sell;

class OZT_Book
{
    private static ref map<string, ref OZT_BookEntry> s_ByClass = new map<string, ref OZT_BookEntry>();

    // From the checked files; called after every load.
    static void Rebuild()
    {
        s_ByClass.Clear();
        OZT_GoodsFile file = OZT_Config.Get().Goods();
        for (int c = 0; c < file.Categories.Count(); c++)
        {
            OZT_Category cat = file.Categories[c];
            for (int g = 0; g < cat.Goods.Count(); g++)
            {
                OZT_Goods line = cat.Goods[g];
                OZT_BookEntry e = new OZT_BookEntry();
                e.ClassName = line.ClassName;
                e.Category = cat.Id;
                e.Buy = line.Buy;
                e.Sell = line.Sell;
                e.Rule = line.Quantity;
                s_ByClass.Set(e.ClassName, e);
            }
        }
    }

    // A 4_World class held by a static: let go at mission end.
    static void Reset()
    {
        s_ByClass.Clear();
    }

    static OZT_BookEntry EntryOf(string type)
    {
        return s_ByClass.Get(type);
    }

    static bool Deals(OZT_Point trader, OZT_BookEntry e)
    {
        if (!trader || !e)
            return false;
        return trader.Categories.Find(e.Category) > -1;
    }

    // What the player pays this trader for `count` of it: units of a stack
    // under the unit rule, pieces otherwise. 0: not sold here.
    static int BuyPrice(OZT_Point trader, OZT_BookEntry e, int count)
    {
        if (count <= 0 || !Deals(trader, e))
            return 0;
        if (e.Buy <= 0)
            return 0;
        int unit = OZT_Config.Get().Unit();
        int piece = OZT_Config.RoundTo(e.Buy * trader.BuyFactor, unit);
        return piece * count;
    }

    // What this trader pays for `count` units of `item` (the count matters
    // under the unit rule only). 0: not taken.
    static int SellPrice(OZT_Point trader, OZT_BookEntry e, EntityAI item, int count)
    {
        if (!item || !Deals(trader, e))
            return 0;
        if (e.Sell <= 0)
            return 0;
        int level = item.GetHealthLevel();
        if (level >= OZT_Const.LEVEL_RUINED)
            return 0;
        float price = e.Sell * trader.SellFactor * OZT_Config.Get().Settings().Condition.Of(level);
        if (e.Rule == OZT_Const.RULE_UNIT)
            price = price * count;
        else if (e.Rule == OZT_Const.RULE_FRACTION)
            price = price * OZT_Stack.Fraction(item);
        int unit = OZT_Config.Get().Unit();
        return OZT_Config.RoundTo(price, unit);
    }
}
```

- [ ] **Step 3: Write `scripts/4_World/OpenZone_Trader/OZT_ItemMoney.c`**

```c
// Item money: banknotes are items, by class, each unit worth what the settings
// say.
//
// The owner's rules (2026-11-10). Paying: notes are taken from the smallest
// value upward until the sum is covered; then, from the smallest again, every
// taken note the sum does not need is put back; what is still overpaid comes
// back as change. Change and payouts are made of the largest notes that make
// the sum.

// One stack of notes the player carries.
class OZT_NoteStack
{
    EntityAI Item;
    int Value;      // of one unit
    int Units;      // in the stack now
    int Spend;      // units a payment takes from it
}

class OZT_ItemMoney : OZT_MoneyProvider
{
    override string Id()
    {
        return OZT_Const.PROVIDER_ITEMS;
    }

    override bool Physical()
    {
        return true;
    }

    override int Unit()
    {
        return OZT_Config.Get().Unit();
    }

    override int Balance(PlayerBase player)
    {
        array<ref OZT_NoteStack> stacks;
        Stacks(player, null, stacks);
        int sum = 0;
        for (int i = 0; i < stacks.Count(); i++)
            sum = sum + stacks[i].Value * stacks[i].Units;
        return sum;
    }

    // What one unit of this class is worth; 0 when it is not a note.
    static int ValueOf(string type)
    {
        array<ref OZT_Note> notes = OZT_Config.Get().Settings().Notes;
        for (int i = 0; i < notes.Count(); i++)
        {
            if (notes[i].ClassName == type)
                return notes[i].Value;
        }
        return 0;
    }

    // Every note stack the player carries, at any depth, the hands included:
    // the smallest value first, and within one value the smaller stack first,
    // so that paying empties whole stacks and frees their cells. `skip` are
    // items that leave in the same deal. A ruined note is not money.
    static void Stacks(PlayerBase player, array<EntityAI> skip, out array<ref OZT_NoteStack> stacks)
    {
        stacks = new array<ref OZT_NoteStack>();
        array<EntityAI> all = new array<EntityAI>();
        player.GetInventory().EnumerateInventory(InventoryTraversalType.PREORDER, all);
        for (int i = 0; i < all.Count(); i++)
        {
            EntityAI e = all[i];
            if (!e || e == player)
                continue;
            if (skip && skip.Find(e) > -1)
                continue;
            int value = ValueOf(e.GetType());
            if (value <= 0 || e.IsRuined())
                continue;
            OZT_NoteStack s = new OZT_NoteStack();
            s.Item = e;
            s.Value = value;
            s.Units = OZT_Stack.Units(e);
            s.Spend = 0;
            if (s.Units <= 0)
                continue;
            int at = 0;
            while (at < stacks.Count() && Before(stacks[at], s))
                at++;
            stacks.InsertAt(s, at);
        }
    }

    private static bool Before(OZT_NoteStack a, OZT_NoteStack b)
    {
        if (a.Value != b.Value)
            return a.Value < b.Value;
        return a.Units <= b.Units;
    }

    // Marks in every stack how many units a payment of `amount` takes
    // (`Spend`) and returns the overpaid sum, which comes back as change; -1
    // when the notes do not cover the amount. `stacks` as Stacks() ordered them.
    static int Pay(array<ref OZT_NoteStack> stacks, int amount)
    {
        int sum = 0;
        for (int i = 0; i < stacks.Count(); i++)
        {
            OZT_NoteStack s = stacks[i];
            s.Spend = 0;
            if (sum >= amount)
                continue;
            int need = amount - sum;
            int units = need / s.Value;
            if (units * s.Value < need)
                units++;
            if (units > s.Units)
                units = s.Units;
            s.Spend = units;
            sum = sum + units * s.Value;
        }
        if (sum < amount)
            return -1;

        // From the smallest again: put back every note the sum does not need.
        for (int k = 0; k < stacks.Count(); k++)
        {
            OZT_NoteStack b = stacks[k];
            int excess = sum - amount;
            int back = excess / b.Value;
            if (back > b.Spend)
                back = b.Spend;
            b.Spend = b.Spend - back;
            sum = sum - back * b.Value;
        }
        return sum - amount;
    }

    // A sum in the largest notes: counts[i] units of Settings.Notes[i]. False
    // when the notes cannot make it (it is not a multiple of the smallest).
    static bool Change(int amount, out array<int> counts)
    {
        counts = new array<int>();
        array<ref OZT_Note> notes = OZT_Config.Get().Settings().Notes;
        for (int z = 0; z < notes.Count(); z++)
            counts.Insert(0);
        int rest = amount;
        for (int i = notes.Count() - 1; i >= 0; i--)
        {
            int n = rest / notes[i].Value;
            counts.Set(i, n);
            rest = rest - n * notes[i].Value;
        }
        return rest == 0;
    }
}
```

```c
// added to KnownVerbs and IsKnownVerb and routed in Dispatch. Every op answers
// within its tick.
//
//   world_exec verb=oz_trader args={"op":"status"}

// Every value of args is a string. The answer is a summary (the bridge cuts it

{
    static bool Run(map<string, string> args, out string detail)
    {
        string op = Arg(args, "op", "status");

        if (op == "status")
        {
            detail = OZT_Module.ReadyLine() + " revision=" + OZT_Config.Get().Revision().ToString();
            return true;
        }

            return OpReload(detail);

        if (!player)

            detail = "nobody is connected: start a client first";
            return false;

        if (op == "balance")
            return OpBalance(player, args, detail);
        if (op == "price")
            return OpPrice(player, args, detail);
        if (op == "pay")
            return OpPay(player, args, detail);
        if (op == "damage")
            return OpDamage(player, args, detail);

    {
        return "status, reload, balance, price, pay, damage";
    }

    static string Arg(map<string, string> args, string key, string fallback)
    {

            return fallback;

        if (args.Find(key, v))
            return v;

    }
```

```c
// Trader points in the world: what stands at each, and how far a player is.
//
// The server makes the object at every start and after every reload, and it is
// never saved to the world (ECE_NOPERSISTENCY_WORLD; a building class is not
// saved anyway). So no class has to be ours, and a point removed from the file
// leaves nothing behind.

class OZT_PointLive
{
    string Id;
    Object Body;
    vector Stands;
}

class OZT_Points
{
    private static ref array<ref OZT_PointLive> s_Live = new array<ref OZT_PointLive>();

    static void Respawn()
    {
        Remove();
        array<ref OZT_Point> traders = OZT_Config.Get().Traders().Traders;
        for (int i = 0; i < traders.Count(); i++)
        {
            OZT_Point p = traders[i];
            vector asked = p.Position();
            int flags = ECE_PLACE_ON_SURFACE | ECE_NOLIFETIME | ECE_NOPERSISTENCY_WORLD;
            Object body = GetGame().CreateObjectEx(p.ClassName, asked, flags);
            if (!body)
            {
                OZT_Log.Error("point '" + p.Id + "': the game made nothing of class '" + p.ClassName + "'");
                continue;
            }
            body.SetOrientation(Vector(p.Yaw, 0, 0));

            OZT_PointLive live = new OZT_PointLive();
            live.Id = p.Id;
            live.Body = body;
            live.Stands = body.GetPosition();
            s_Live.Insert(live);

            // The place it really took, not the one asked for: "the stall sank
            // into the ground" has to be visible in the log.
            string line = "point '" + p.Id + "' (" + p.ClassName + ") stands at " + live.Stands.ToString();
            OZT_Log.Info(line);
        }
    }

    static void Remove()
    {
        for (int i = 0; i < s_Live.Count(); i++)
        {
            if (s_Live[i].Body)
                GetGame().ObjectDelete(s_Live[i].Body);
        }
        s_Live.Clear();
    }

    // How far the player stands from the point, in metres. Below zero: the
    // point does not stand.
    static float Away(string id, PlayerBase player)
    {
        for (int i = 0; i < s_Live.Count(); i++)
        {
            if (s_Live[i].Id != id)
                continue;
            vector there = s_Live[i].Stands;
            vector here = player.GetPosition();
            return vector.Distance(here, there);
        }
        return -1;
    }

    static int Standing()
    {
        return s_Live.Count();
    }
}
```

```c
// The service `trader` in the core's registry: what a client asks.
//
// The core's dispatcher checks only what every service shares (the sender's
// identity, the size of the body). Who may trade, where and what is checked
// here. A refusal is a string-table key, never a sentence.

class OZT_Open
{
    // The answer of `open`: the trader, what this player may buy and sell here
    // and for how much, and the player's money. Prices carry the trader's own
    // factors already.
    static string Answer(PlayerBase player, string json, out bool ok, out string error)
    {
        ok = false;
        error = OZT_Const.NO_INTERNAL;

        OZT_OpenReq req = new OZT_OpenReq();
        string err;
        if (!JsonFileLoader<OZT_OpenReq>.LoadData(json, req, err))
        {
            OZT_Log.Dbg("open refused: unreadable body (" + err + ")");
            return "";
        }

        OZT_Point trader = OZT_Config.Get().FindTrader(req.Trader);
        float away = -1;
        if (trader)
            away = OZT_Points.Away(trader.Id, player);
        if (away < 0)
        {
            error = OZT_Const.NO_CLOSED;
            return "";
        }
        if (away > trader.Radius)
        {
            error = OZT_Const.NO_TOO_FAR;
            return "";
        }

        OZT_MoneyProvider money = OZT_Money.Of(trader);
        if (!money)
            return "";

        OZT_OpenRes res = new OZT_OpenRes();
        res.Revision = OZT_Config.Get().Revision();
        res.Trader = trader.Id;
        res.Name = trader.Name;
        res.Radius = trader.Radius;
        res.Provider = money.Id();
        if (money.Physical())
            res.Physical = 1;
        res.Unit = money.Unit();
        res.Label = money.Label();
        res.Balance = money.Balance(player);
        res.WearBought = OZT_Config.Get().Settings().WearBought;
        res.Condition = OZT_Config.Get().Settings().Condition.Copy();

        int unit = OZT_Config.Get().Unit();
        for (int c = 0; c < trader.Categories.Count(); c++)
        {
            OZT_Category cat = OZT_Config.Get().FindCategory(trader.Categories[c]);
            if (!cat)
                continue;
            OZT_WireCategory wc = new OZT_WireCategory();
            wc.Id = cat.Id;
            wc.Name = cat.Name;
            res.Categories.Insert(wc);

            for (int g = 0; g < cat.Goods.Count(); g++)
            {
                OZT_BookEntry e = OZT_Book.EntryOf(cat.Goods[g].ClassName);
                if (!e)
                    continue;
                OZT_WireGoods wg = new OZT_WireGoods();
                wg.ClassName = e.ClassName;
                wg.Category = e.Category;
                wg.Buy = OZT_Book.BuyPrice(trader, e, 1);
                if (e.Sell > 0)
                    wg.Sell = OZT_Config.RoundTo(e.Sell * trader.SellFactor, unit);
                wg.Rule = e.Rule;
                if (wg.Buy <= 0 && wg.Sell <= 0)
                    continue;
                res.Goods.Insert(wg);
            }
        }

        string body;
        if (!JsonFileLoader<OZT_OpenRes>.MakeData(res, body, err, false))
        {
            OZT_Log.Error("open: the answer could not be written: " + err);
            return "";
        }
        ok = true;
        error = "";
        return body;
    }
}
```

```c
// The character's inventory as a deal's plan sees it.
//
// A deal places several new things at once, and no engine query can do that:
// every query answers about the inventory as it is NOW. So the plan keeps a
// picture of its own -- every cargo the character carries as a grid of taken
// cells, the character's slots, the hands -- leaves out of it what the deal
// takes away, and marks every place it gives. The engine is asked two things
// only, with a local entity of the class that no client ever sees: how big the
// thing is, and whether a holder's script gate takes it.
//
// What this rests on was measured in phase 0
// (docs/measurements/2026-11-11/answers.md): a picture built from each item's
// own inventory location agrees with the engine on every cell; a creation at a
// place the picture calls free succeeds in the very call in which the things
// that stood there were deleted with ObjectDelete; a gate's answer does not
// depend on the cell.
//
// The reading of a cargo is the storage mod's (OZS_Ops.c): the cell from the
// item's own location, never CargoBase.GetItemRowCol; the size from
// CargoBase.GetItemSize by cargo index, whose return value is not to be trusted
// while its numbers are.

// A place a plan gives to a thing that does not exist yet.
class OZT_Place
{
    int Kind;
    EntityAI Holder;
    int Row;
    int Col;
    bool Turned;
    int SlotId;

    string Text()
    {
        if (Kind == InventoryLocationType.HANDS)
            return "HANDS";
        if (Kind == InventoryLocationType.ATTACHMENT)
            return "SLOT " + InventorySlots.GetSlotName(SlotId);
        string s = "CARGO " + Holder.GetType() + " r" + Row.ToString() + " c" + Col.ToString();
        if (Turned)
            s = s + " turned";
        return s;
    }
}

// The cargo of one holder as the plan sees it.
class OZT_Grid
{
    EntityAI Holder;
    int W;
    int H;
    ref array<bool> Taken;
    bool ForNotes;

    bool IsFree(int row, int col, int w, int h)
    {
        if (row < 0 || col < 0 || w <= 0 || h <= 0)
            return false;
        if (row + h > H || col + w > W)
            return false;
        for (int r = row; r < row + h; r++)
        {
            for (int c = col; c < col + w; c++)
            {
                if (Taken[r * W + c])
                    return false;
            }
        }
        return true;
    }

    void Mark(int row, int col, int w, int h)
    {
        for (int r = row; r < row + h; r++)
        {
            for (int c = col; c < col + w; c++)
            {
                if (r >= 0 && r < H && c >= 0 && c < W)
                    Taken.Set(r * W + c, true);
            }
        }
    }

    // The first free place for a w x h thing, row by row: every unturned place
    // before any turned one.
    bool Seek(int w, int h, out int row, out int col, out bool turned)
    {
        turned = false;
        if (SeekAs(w, h, row, col))
            return true;
        if (w == h)
            return false;
        turned = true;
        return SeekAs(h, w, row, col);
    }

    protected bool SeekAs(int w, int h, out int row, out int col)
    {
        row = -1;
        col = -1;
        for (int r = 0; r + h <= H; r++)
        {
            for (int c = 0; c + w <= W; c++)
            {
                if (IsFree(r, c, w, h))
                {
                    row = r;
                    col = c;
                    return true;
                }
            }
        }
        return false;
    }

class OZT_InvModel
{
    protected PlayerBase m_Player;
    protected ref array<EntityAI> m_Gone;
    protected ref array<ref OZT_Grid> m_Grids;
    protected ref array<int> m_SlotsTaken;
    protected bool m_HandsFree;
    protected ref map<string, EntityAI> m_Probes;
    protected ref map<string, int> m_Gates;

    // The countable things the player keeps, and how many units each will hold
    // when the deal is done.
    protected ref array<EntityAI> m_Stacks;
    protected ref array<int> m_StackUnits;

    // `gone` is what leaves in this deal: the things sold whole and the note
    // stacks a payment spends whole. Their cells, slots and hands count as free.
    void OZT_InvModel(PlayerBase player, array<EntityAI> gone)
    {
        m_Player = player;
        m_Gone = new array<EntityAI>();
        if (gone)
        {
            for (int i = 0; i < gone.Count(); i++)
                m_Gone.Insert(gone[i]);
        }
        m_Grids = new array<ref OZT_Grid>();
        m_SlotsTaken = new array<int>();
        m_Probes = new map<string, EntityAI>();
        m_Gates = new map<string, int>();
        m_Stacks = new array<EntityAI>();
        m_StackUnits = new array<int>();
        Read();
    }

    // ---- reading -------------------------------------------------------------

    protected void Read()
    {
        // The engine's own order: what the character wears, then what hangs on
        // that, then what lies inside. It is the order new things try holders in.
        array<EntityAI> all = new array<EntityAI>();
        m_Player.GetInventory().EnumerateInventory(InventoryTraversalType.PREORDER, all);
        for (int i = 0; i < all.Count(); i++)
        {
            EntityAI e = all[i];
            if (!e || e == m_Player)
                continue;
            if (m_Gone.Find(e) > -1)
                continue;
            if (OZT_Stack.Countable(e) && !e.IsRuined())
            {
                int units = OZT_Stack.Units(e);
                m_Stacks.Insert(e);
                m_StackUnits.Insert(units);
            }
            CargoBase cargo = e.GetInventory().GetCargo();
            if (cargo && cargo.GetWidth() > 0 && cargo.GetHeight() > 0)
                m_Grids.Insert(GridOf(e, cargo));
        }

        int worn = m_Player.GetInventory().AttachmentCount();
        for (int a = 0; a < worn; a++)
        {
            EntityAI w = m_Player.GetInventory().GetAttachmentFromIndex(a);
            if (!w || m_Gone.Find(w) > -1)
                continue;
            InventoryLocation il = new InventoryLocation();
            if (w.GetInventory().GetCurrentInventoryLocation(il))
                m_SlotsTaken.Insert(il.GetSlot());
        }

        EntityAI held = m_Player.GetHumanInventory().GetEntityInHands();
        bool free = true;
        if (held && m_Gone.Find(held) < 0)
            free = false;
        m_HandsFree = free;
    }

    protected OZT_Grid GridOf(EntityAI holder, CargoBase cargo)
    {
        OZT_Grid g = new OZT_Grid();
        g.Holder = holder;
        g.W = cargo.GetWidth();
        g.H = cargo.GetHeight();
        g.Taken = new array<bool>();
        int cells = g.W * g.H;
        for (int k = 0; k < cells; k++)
            g.Taken.Insert(false);
        g.ForNotes = IsNoteHolder(holder);

        int n = cargo.GetItemCount();
        for (int i = 0; i < n; i++)
        {
            EntityAI it = cargo.GetItem(i);
            if (!it || m_Gone.Find(it) > -1)
                continue;
            InventoryLocation il = new InventoryLocation();
            if (!it.GetInventory().GetCurrentInventoryLocation(il))
                continue;
            int w;
            int h;
            cargo.GetItemSize(i, w, h);
            if (w <= 0 || h <= 0)
                continue;
            if (il.GetFlip())
            {
                int turned = w;
                w = h;
                h = turned;
            }
            g.Mark(il.GetRow(), il.GetCol(), w, h);
        }
        return g;
    }

    static bool IsNoteHolder(EntityAI e)
    {
        array<string> holders = OZT_Config.Get().Settings().Holders;
        for (int i = 0; i < holders.Count(); i++)
        {
            if (e.IsKindOf(holders[i]))
                return true;
        }
        return false;
    }

    // ---- asking the engine -----------------------------------------------------

    // One local entity per class, on the ground at the character's feet, never
    // announced to a client and never saved; Dispose() deletes them all in the
    // same call. Null: the game makes no such thing.
    EntityAI ProbeOf(string type)
    {
        EntityAI probe;
        if (m_Probes.Find(type, probe))
            return probe;
        vector feet = m_Player.GetPosition();
        probe = EntityAI.Cast(GetGame().CreateObjectEx(type, feet, ECE_LOCAL | ECE_NOPERSISTENCY_WORLD));
        m_Probes.Set(type, probe);
        return probe;
    }

    protected bool SizeOfClass(string type, out int w, out int h)
    {
        w = 0;
        h = 0;
        EntityAI probe = ProbeOf(type);
        if (!probe)
            return false;
        GetGame().GetInventoryItemSize(InventoryItem.Cast(probe), w, h);
        return w > 0 && h > 0;
    }

    // The cells one thing of the class takes: what a deal sorts its lines by.
    // 0: the game makes no such thing.
    int AreaOf(string type)
    {
        int w;
        int h;
        if (!SizeOfClass(type, w, h))
            return 0;
        return w * h;
    }

    // Does this holder's cargo take the class: the item check and the script
    // check with the occupancy test off (the flags phase 0 measured). Asked once
    // per holder and class.
    protected bool Accepts(OZT_Grid g, string type)
    {
        string key = g.Holder.GetNetworkIDString() + "|" + type;
        int known;
        if (m_Gates.Find(key, known))
            return known == 1;

        bool yes = false;
        EntityAI probe = ProbeOf(type);
        if (probe)
            yes = g.Holder.GetInventory().TestAddEntityInCargoEx(probe, 0, 0, 0, false, false, true, false, false, true, false);
        int mark = 0;
        if (yes)
            mark = 1;
        m_Gates.Set(key, mark);
        return yes;
    }

    // The slot names a class may sit on, from its own config.
    protected void SlotNamesOf(string type, array<string> names)
    {
        array<string> roots = {"CfgVehicles", "CfgWeapons", "CfgMagazines"};
        for (int i = 0; i < roots.Count(); i++)
        {
            string path = roots[i] + " " + type + " inventorySlot";
            if (!GetGame().ConfigIsExisting(path))
                continue;
            if (GetGame().ConfigGetType(path) == CT_ARRAY)
            {
                GetGame().ConfigGetTextArray(path, names);
                return;
            }
            string one;
            GetGame().ConfigGetText(path, one);
            if (one != "")
                names.Insert(one);
            return;
        }
    }

    // ---- placing -----------------------------------------------------------------

    // A free slot of the character that the class may sit on. The slot may hold
    // a thing this deal sells, so occupancy is the plan's to know and the engine
    // is asked for its gates alone. Marks the slot.
    bool PlaceOnSlot(string type, out OZT_Place place)
    {
        place = null;
        EntityAI probe = ProbeOf(type);
        if (!probe)
            return false;
        array<string> names = new array<string>();
        SlotNamesOf(type, names);
        for (int i = 0; i < names.Count(); i++)
        {
            int slot = InventorySlots.GetSlotIdFromString(names[i]);
            if (slot == InventorySlots.INVALID)
                continue;
            if (!m_Player.GetInventory().HasAttachmentSlot(slot))
                continue;
            if (m_SlotsTaken.Find(slot) > -1)
                continue;
            InventoryLocation loc = new InventoryLocation();
            loc.SetAttachment(m_Player, probe, slot);
            if (!GameInventory.LocationTestAddEntity(loc, false, true, false, false, true, false))
                continue;
            m_SlotsTaken.Insert(slot);
            place = new OZT_Place();
            place.Kind = InventoryLocationType.ATTACHMENT;
            place.Holder = m_Player;
            place.Row = -1;
            place.Col = -1;
            place.Turned = false;
            place.SlotId = slot;
            return true;
        }
        return false;
    }

    // The first cargo place for a new thing of the class: holders in the
    // engine's order (the note holders first when `notesFirst`), each asked for
    // its gate once. Marks the cells.
    bool PlaceInCargo(string type, bool notesFirst, out OZT_Place place)
    {
        place = null;
        int w;
        int h;
        if (!SizeOfClass(type, w, h))
            return false;

        array<OZT_Grid> order = new array<OZT_Grid>();
        if (notesFirst)
        {
            for (int a = 0; a < m_Grids.Count(); a++)
            {
                if (m_Grids[a].ForNotes)
                    order.Insert(m_Grids[a]);
            }
            for (int b = 0; b < m_Grids.Count(); b++)
            {
                if (!m_Grids[b].ForNotes)
                    order.Insert(m_Grids[b]);
            }
        }
        else
        {
            for (int c = 0; c < m_Grids.Count(); c++)
                order.Insert(m_Grids[c]);
        }

        for (int i = 0; i < order.Count(); i++)
        {
            OZT_Grid g = order[i];
            int row;
            int col;
            bool turned;
            if (!g.Seek(w, h, row, col, turned))
                continue;
            if (!Accepts(g, type))
                continue;
            if (turned)
                g.Mark(row, col, h, w);
            else
                g.Mark(row, col, w, h);
            place = new OZT_Place();
            place.Kind = InventoryLocationType.CARGO;
            place.Holder = g.Holder;
            place.Row = row;
            place.Col = col;
            place.Turned = turned;
            place.SlotId = InventorySlots.INVALID;
            return true;
        }
        return false;
    }

    // The hands, for the one thing that found no other place. In a vehicle the
    // hands count as busy (a rule of the design, not a measurement).
    bool PlaceInHands(string type, out OZT_Place place)
    {
        place = null;
        if (!m_HandsFree || m_Player.IsInVehicle())
            return false;
        EntityAI probe = ProbeOf(type);
        if (!probe)
            return false;

        HumanInventory hands = m_Player.GetHumanInventory();
        bool can;
        if (hands.GetEntityInHands())
            can = hands.TestAddEntityInHands(probe, false, true, false, false, true);
        else
            can = hands.CanAddEntityInHands(probe);
        if (!can)
            return false;

        m_HandsFree = false;
        place = new OZT_Place();
        place.Kind = InventoryLocationType.HANDS;
        place.Holder = m_Player;
        place.Row = -1;
        place.Col = -1;
        place.Turned = false;
        place.SlotId = InventorySlots.INVALID;
        return true;
    }

    // ---- stacks the player keeps -------------------------------------------------

    // How many units a kept stack will hold after the deal, as planned so far.
    // -1: the model does not count the thing.
    int PlannedUnits(EntityAI stack)
    {
        int at = m_Stacks.Find(stack);
        if (at < 0)
            return -1;
        return m_StackUnits[at];
    }

    void PlanUnits(EntityAI stack, int units)
    {
        int at = m_Stacks.Find(stack);
        if (at > -1)
            m_StackUnits.Set(at, units);
    }

    // The stacks of a class that lie in a cargo and have room, with the room of
    // each as planned so far; with `notesFirst` the ones inside note holders
    // come first.
    void StacksWithRoom(string type, bool notesFirst, out array<EntityAI> stacks, out array<int> room)
    {
        stacks = new array<EntityAI>();
        room = new array<int>();
        for (int pass = 0; pass < 2; pass++)
        {
            for (int i = 0; i < m_Stacks.Count(); i++)
            {
                EntityAI s = m_Stacks[i];
                if (!s || s.GetType() != type)
                    continue;
                InventoryLocation il = new InventoryLocation();
                if (!s.GetInventory().GetCurrentInventoryLocation(il))
                    continue;
                if (il.GetType() != InventoryLocationType.CARGO)
                    continue;
                bool inHolder = IsNoteHolder(il.GetParent());
                bool first = inHolder && notesFirst;
                if (pass == 0 && !first)
                    continue;
                if (pass == 1 && first)
                    continue;
                int free = OZT_Stack.Max(s) - m_StackUnits[i];
                if (free <= 0)
                    continue;
                stacks.Insert(s);
                room.Insert(free);
            }
        }
    }

    // ---- making what was planned ----------------------------------------------------

    // Creates a thing at its planned place, the way phase 0 measured. Null: the
    // engine refused, and nothing was created anywhere.
    static EntityAI Make(PlayerBase player, OZT_Place place, string type)
    {
        InventoryLocation loc = new InventoryLocation();
        if (place.Kind == InventoryLocationType.HANDS)
            loc.SetHands(player, null);
        else if (place.Kind == InventoryLocationType.ATTACHMENT)
            loc.SetAttachment(place.Holder, null, place.SlotId);
        else
            loc.SetCargo(place.Holder, null, 0, place.Row, place.Col, place.Turned);
        return GameInventory.LocationCreateEntity(loc, type, ECE_IN_INVENTORY, RF_DEFAULT);
    }

    // Does the thing stand where the plan put it?
    static bool Stands(EntityAI e, OZT_Place place)
    {
        if (!e)
            return false;
        InventoryLocation il = new InventoryLocation();
        if (!e.GetInventory().GetCurrentInventoryLocation(il))
            return false;
        if (il.GetType() != place.Kind)
            return false;
        if (place.Kind == InventoryLocationType.ATTACHMENT)
            return il.GetSlot() == place.SlotId;
        if (place.Kind != InventoryLocationType.CARGO)
            return true;
        if (il.GetParent() != place.Holder)
            return false;
        if (il.GetRow() != place.Row || il.GetCol() != place.Col)
            return false;
        return il.GetFlip() == place.Turned;
    }

    void Dispose()
    {
        for (int i = 0; i < m_Probes.Count(); i++)
        {
            EntityAI probe = m_Probes.GetElement(i);
            if (probe)
                GetGame().ObjectDelete(probe);
        }
        m_Probes.Clear();
    }
```

```c
    // A list of things in an argument: Class[:count][#nth], separated by commas.
    // count 0 means "not given"; nth picks among several the player carries.
    static void Items(string list, out array<string> names, out array<int> counts, out array<int> nths)
    {
        names = new array<string>();
        counts = new array<int>();
        nths = new array<int>();
        if (list == "")
            return;
        array<string> tokens = new array<string>();
        list.Split(",", tokens);
        for (int i = 0; i < tokens.Count(); i++)
        {
            string token = tokens[i].Trim();
            if (token == "")
                continue;
            int nth = 0;
            int hash = token.IndexOf("#");
            if (hash > -1)
            {
                int afterHash = token.Length() - hash - 1;
                nth = token.Substring(hash + 1, afterHash).ToInt();
                token = token.Substring(0, hash);
            }
            int count = 0;
            int colon = token.IndexOf(":");
            if (colon > -1)
            {
                int afterColon = token.Length() - colon - 1;
                count = token.Substring(colon + 1, afterColon).ToInt();
                token = token.Substring(0, colon);
            }
            names.Insert(token);
            counts.Insert(count);
            nths.Insert(nth);
        }
    }

    // fit [buy=Class:n,...] [notes=Class:n,...] [gone=Class#nth,...] [make=1]:
    // where a plan puts new things, with the `gone` things taken out of the
    // picture. buy: n pieces, a free slot first when the settings wear bought
    // gear, then cargo. notes: n new stacks, note holders first. One thing with
    // no place goes to free hands. With make=1 the gone things are deleted and
    // every planned thing is created at its place in the same call, as a commit
    // does, and what the engine did is compared with the plan.
    static bool OpFit(PlayerBase player, map<string, string> args, out string detail)
    {
        array<string> names;
        array<int> counts;
        array<int> nths;

        array<EntityAI> gone = new array<EntityAI>();
        Items(Arg(args, "gone", ""), names, counts, nths);
        for (int g = 0; g < names.Count(); g++)
        {
            EntityAI leaving = Carried(player, names[g], nths[g]);
            if (!leaving)
            {
                detail = "fit: the player carries no " + names[g] + " number " + nths[g].ToString();
                return false;
            }
            gone.Insert(leaving);
        }

        OZT_InvModel model = new OZT_InvModel(player, gone);
        bool wear = OZT_Config.Get().Settings().WearBought == 1;
        array<string> classes = new array<string>();
        array<ref OZT_Place> places = new array<ref OZT_Place>();
        array<string> homeless = new array<string>();
        string report = "";

        Items(Arg(args, "buy", ""), names, counts, nths);
        for (int b = 0; b < names.Count(); b++)
        {
            int pieces = counts[b];
            if (pieces < 1)
                pieces = 1;
            for (int n = 0; n < pieces; n++)
            {
                OZT_Place place;
                bool placed = false;
                if (wear)
                    placed = model.PlaceOnSlot(names[b], place);
                if (!placed)
                    placed = model.PlaceInCargo(names[b], false, place);
                if (!placed)
                {
                    homeless.Insert(names[b]);
                    continue;
                }
                classes.Insert(names[b]);
                places.Insert(place);
                report = report + " | " + names[b] + ": " + place.Text();
            }
        }

        Items(Arg(args, "notes", ""), names, counts, nths);
        for (int s = 0; s < names.Count(); s++)
        {
            int piles = counts[s];
            if (piles < 1)
                piles = 1;
            for (int k = 0; k < piles; k++)
            {
                OZT_Place spot;
                if (!model.PlaceInCargo(names[s], true, spot))
                {
                    homeless.Insert(names[s]);
                    continue;
                }
                classes.Insert(names[s]);
                places.Insert(spot);
                report = report + " | " + names[s] + ": " + spot.Text();
            }
        }

        int unplaced = homeless.Count();
        if (unplaced == 1)
        {
            OZT_Place hands;
            if (model.PlaceInHands(homeless[0], hands))
            {
                classes.Insert(homeless[0]);
                places.Insert(hands);
                report = report + " | " + homeless[0] + ": HANDS";
                unplaced = 0;
            }
        }
        for (int u = 0; u < homeless.Count() && unplaced > 0; u++)
            report = report + " | " + homeless[u] + ": NO PLACE";

        string head = "fit: placed=" + classes.Count().ToString() + " unplaced=" + unplaced.ToString();
        if (Arg(args, "make", "0") == "1")
        {
            for (int d = 0; d < gone.Count(); d++)
                GetGame().ObjectDelete(gone[d]);
            int made = 0;
            int asPlanned = 0;
            for (int m = 0; m < classes.Count(); m++)
            {
                EntityAI fresh = OZT_InvModel.Make(player, places[m], classes[m]);
                if (!fresh)
                    continue;
                made++;
                if (OZT_InvModel.Stands(fresh, places[m]))
                    asPlanned++;
            }
            head = head + " made=" + made.ToString() + " where planned=" + asPlanned.ToString();
        }
        model.Dispose();

        SaveAnswer(head + report);
        detail = head + report;
        return true;
    }
```

```c
// One thing the player sells: the entity by the two halves of its network id,
// and how many units of it when it is a stack (0: all of it).
class OZT_WireSell
{
    int Low = 0;
    int High = 0;
    int Count = 0;

    OZT_WireSell Copy()
    {
        OZT_WireSell c = new OZT_WireSell();
        c.Low = Low;
        c.High = High;
        c.Count = Count;
        return c;
    }
}

// Goods the player buys, by class: pieces, or units under the unit rule.
class OZT_WireBuy
{
    string ClassName = "";
    int Count = 0;

    OZT_WireBuy Copy()
    {
        OZT_WireBuy c = new OZT_WireBuy();
        c.ClassName = ClassName;
        c.Count = Count;
        return c;
    }
}

class OZT_DealReq
{
    string Trader = "";
    ref array<ref OZT_WireSell> Sells;
    ref array<ref OZT_WireBuy> Buys;

    // The net the client showed: what the player pays (above zero) or is paid
    // (below). The server computes its own and refuses a deal whose net differs.
    int Net = 0;

    void OZT_DealReq()
    {
        Sells = new array<ref OZT_WireSell>();
        Buys = new array<ref OZT_WireBuy>();
    }
}

class OZT_DealRes
{
    // The server's own net, on a refusal too: after `changed` the client shows it.
    int Net = 0;
    int Paid = 0;
    int Received = 0;
    int Balance = 0;

    // The class of the one thing that went to the hands; "" when none did.
    string InHands = "";

    // The number a refusal carries: things that do not fit (no space), things
    // in the way (not empty).
    int Left = 0;
}
```

- [ ] **Step 2: Write `scripts/4_World/OpenZone_Trader/OZT_Deal.c`**

```c
// A deal: one cart of sells and buys, settled in one step or not at all.
//
// The server is the judge. It resolves every sold entity itself, computes every
// price itself, and plans every place before anything changes (design §4.3):
//
//   1. the player and the trader      who, where, doing nothing else
//   2. the sells                      yours, taken here, plain
//   3. the buys and the net           compared with what the client showed
//   4. the money                      enough of it; which notes; what comes back
//   5. the places                     everything bought and every note given
//   6. the commit                     ONE script call
//
// The commit's order is phase 0's: what leaves is deleted with ObjectDelete,
// which frees its place at once; stacks shrink; new things are created at their
// planned places; stacks grow. No frame passes in between.
//
// Phase 1 sells and buys plain things. An item that has something hanging on
// it, lying in it or loaded into it is refused as "not empty"; phase 3 sells
// such an item as a tree.

// A stack the player keeps, grown (a merge) or shrunk (a part sold or paid).
class OZT_Grow
{
    EntityAI Stack;
    int Units;
}

// A thing the commit creates.
class OZT_Make
{
    string ClassName;
    ref OZT_Place Place;

    // Above zero: a stack of this many units. Zero: as the game makes it.
    int Units;
}

class OZT_Deal
{
    // The most one line may ask for: pieces, and units under the unit rule.
    static const int MAX_PIECES = 50;
    static const int MAX_UNITS = 5000;

    // When each player last made a deal: uid -> the game's milliseconds.
    protected static ref map<string, int> s_Last = new map<string, int>();

    protected PlayerBase m_Player;
    protected OZT_Point m_Trader;
    protected OZT_MoneyProvider m_Money;
    protected ref OZT_InvModel m_Model;
    protected ref OZT_DealRes m_Res;

    protected ref array<EntityAI> m_Gone;
    protected ref array<ref OZT_Grow> m_Grows;
    protected ref array<ref OZT_Make> m_Makes;
    protected ref array<string> m_BuyClasses;
    protected ref array<int> m_BuyCounts;
    protected ref array<string> m_BuyRules;
    protected ref array<string> m_Homeless;
    protected ref array<int> m_HomelessUnits;

    // True while a plan is laid with the first thing that needs cells set aside
    // for the hands: the second laying of PlanPlaces.
    protected bool m_Aside;

    protected int m_Net;
    protected int m_Give;
    protected string m_Lines;

    // The whole of it, as the JSON of an OZT_DealRes. `commit` false is a quote:
    // every check and the whole plan, nothing changed, the net not compared.
    static string Run(PlayerBase player, string json, bool commit, out bool ok, out string error)
    {
        OZT_Deal deal = new OZT_Deal(player);
        error = deal.Go(json, commit);
        ok = error == "";
        string body = deal.Body();
        deal.Close();
        return body;
    }

    // 4_World classes held by a static: let go at mission end.
    static void Reset()
    {
        s_Last.Clear();
    }

    void OZT_Deal(PlayerBase player)
    {
        m_Player = player;
        m_Res = new OZT_DealRes();
        m_Gone = new array<EntityAI>();
        m_Grows = new array<ref OZT_Grow>();
        m_Makes = new array<ref OZT_Make>();
        m_BuyClasses = new array<string>();
        m_BuyCounts = new array<int>();
        m_BuyRules = new array<string>();
        m_Homeless = new array<string>();
        m_HomelessUnits = new array<int>();
        m_Lines = "";
    }

    string Body()
    {
        string body;
        string err;
        JsonFileLoader<OZT_DealRes>.MakeData(m_Res, body, err, false);
        return body;
    }

    void Close()
    {
        if (m_Model)
            m_Model.Dispose();
    }

    protected string Uid()
    {
        PlayerIdentity id = m_Player.GetIdentity();
        if (!id)
            return "";
        return id.GetPlainId();
    }

    // Returns "" when the deal stands, or the key of the refusal.
    string Go(string json, bool commit)
    {
        OZT_DealReq req = new OZT_DealReq();
        string err;
        if (!JsonFileLoader<OZT_DealReq>.LoadData(json, req, err))
        {
            OZT_Log.Dbg("deal refused: unreadable body (" + err + ")");
            return OZT_Const.NO_INTERNAL;
        }

        // What arrived was allocated by the loader: read once, now, into our own.
        array<ref OZT_WireSell> sells = new array<ref OZT_WireSell>();
        if (req.Sells)
        {
            for (int s = 0; s < req.Sells.Count(); s++)
            {
                if (req.Sells[s])
                    sells.Insert(req.Sells[s].Copy());
            }
        }
        array<ref OZT_WireBuy> buys = new array<ref OZT_WireBuy>();
        if (req.Buys)
        {
            for (int b = 0; b < req.Buys.Count(); b++)
            {
                if (req.Buys[b])
                    buys.Insert(req.Buys[b].Copy());
            }
        }
        string traderId = req.Trader;
        int shown = req.Net;

        string why = CheckPlayer(traderId, commit);
        if (why != "")
            return why;
        why = ReadSells(sells);
        if (why != "")
            return why;
        why = ReadBuys(buys);
        if (why != "")
            return why;

        m_Res.Net = m_Net;
        if (commit && shown != m_Net)
            return OZT_Const.NO_CHANGED;

        why = PlanMoney();
        if (why != "")
            return why;
        why = PlanPlaces();
        if (why != "")
            return why;

        if (m_Net > 0)
            m_Res.Paid = m_Net;
        else
            m_Res.Received = -m_Net;

        if (!commit)
        {
            m_Res.Balance = m_Money.Balance(m_Player) - m_Net;
            return "";
        }
        return Commit();
    }

    // ---- 1. the player and the trader ------------------------------------------

    protected string CheckPlayer(string traderId, bool commit)
    {
        if (!m_Player.IsAlive() || m_Player.IsUnconscious() || m_Player.IsRestrained())
            return OZT_Const.NO_BUSY;

        // "The player is doing nothing with their things": vanilla's own check,
        // read in phase 0.
        bool acting = false;
        if (m_Player.GetActionManager() && m_Player.GetActionManager().GetRunningAction())
            acting = true;
        if (acting || !m_Player.CanDeleteItems())
            return OZT_Const.NO_BUSY;
        if (m_Player.GetDayZPlayerInventory().IsProcessing())
            return OZT_Const.NO_BUSY;

        m_Trader = OZT_Config.Get().FindTrader(traderId);
        float away = -1;
        if (m_Trader)
            away = OZT_Points.Away(m_Trader.Id, m_Player);
        if (away < 0)
            return OZT_Const.NO_CLOSED;
        if (away > m_Trader.Radius)
            return OZT_Const.NO_TOO_FAR;

        m_Money = OZT_Money.Of(m_Trader);
        if (!m_Money)
            return OZT_Const.NO_INTERNAL;

        if (commit)
        {
            int last;
            if (s_Last.Find(Uid(), last))
            {
                int since = GetGame().GetTime() - last;
                if (since < OZT_Config.Get().Settings().CooldownMs)
                    return OZT_Const.NO_BUSY;
            }
        }
        return "";
    }

    // ---- 2. the sells ----------------------------------------------------------

    protected string ReadSells(array<ref OZT_WireSell> sells)
    {
        int total = 0;
        for (int i = 0; i < sells.Count(); i++)
        {
            OZT_WireSell line = sells[i];
            EntityAI e = EntityAI.Cast(GetGame().GetObjectByNetworkId(line.Low, line.High));
            if (!e || e.GetHierarchyRootPlayer() != m_Player)
                return OZT_Const.NO_NOT_YOURS;
            if (m_Gone.Find(e) > -1 || Shrinking(e))
                return OZT_Const.NO_INTERNAL;

            int units = 1;
            bool whole = true;
            if (OZT_Stack.Countable(e))
            {
                units = OZT_Stack.Units(e);
                if (line.Count > 0 && line.Count < units)
                {
                    units = line.Count;
                    whole = false;
                }
            }

            // "Not taken" before "not empty": if the trader does not want the
            // thing, emptying it would not help. A ruined thing prices at zero.
            OZT_BookEntry entry = OZT_Book.EntryOf(e.GetType());
            int price = OZT_Book.SellPrice(m_Trader, entry, e, units);
            if (price <= 0)
                return OZT_Const.NO_NOT_TAKEN;

            int inside = InTheWay(e);
            if (inside > 0)
            {
                m_Res.Left = inside;
                return OZT_Const.NO_NOT_EMPTY;
            }

            total = total + price;
            if (whole)
                m_Gone.Insert(e);
            else
                AddGrow(e, -units);
            m_Lines = m_Lines + " -" + e.GetType() + "x" + units.ToString() + "=" + price.ToString();
        }
        m_Net = m_Net - total;
        return "";
    }

    protected bool Shrinking(EntityAI e)
    {
        for (int i = 0; i < m_Grows.Count(); i++)
        {
            if (m_Grows[i].Stack == e)
                return true;
        }
        return false;
    }

    // What hangs on a thing, lies in it or is loaded into it.
    protected int InTheWay(EntityAI e)
    {
        int n = e.GetInventory().AttachmentCount();
        CargoBase cargo = e.GetInventory().GetCargo();
        if (cargo)
            n = n + cargo.GetItemCount();

        Magazine mag = Magazine.Cast(e);
        if (mag && !mag.IsAmmoPile())
            n = n + mag.GetAmmoCount();

        Weapon wpn = Weapon.Cast(e);
        if (wpn)
        {
            for (int m = 0; m < wpn.GetMuzzleCount(); m++)
            {
                if (!wpn.IsChamberEmpty(m))
                    n++;
                n = n + wpn.GetInternalMagazineCartridgeCount(m);
            }
        }
        return n;
    }

    // ---- 3. the buys -------------------------------------------------------------

    protected string ReadBuys(array<ref OZT_WireBuy> buys)
    {
        int total = 0;
        for (int i = 0; i < buys.Count(); i++)
        {
            OZT_WireBuy line = buys[i];
            OZT_BookEntry entry = OZT_Book.EntryOf(line.ClassName);

            // Goods this trader does not sell: the catalogue the client holds
            // is stale.
            int price = OZT_Book.BuyPrice(m_Trader, entry, line.Count);
            if (price <= 0)
                return OZT_Const.NO_CHANGED;

            int most = MAX_PIECES;
            if (entry.Rule == OZT_Const.RULE_UNIT)
                most = MAX_UNITS;
            if (line.Count > most)
                return OZT_Const.NO_INTERNAL;

            total = total + price;
            m_BuyClasses.Insert(entry.ClassName);
            m_BuyCounts.Insert(line.Count);
            m_BuyRules.Insert(entry.Rule);
            m_Lines = m_Lines + " +" + entry.ClassName + "x" + line.Count.ToString() + "=" + price.ToString();
        }
        m_Net = m_Net + total;
        return "";
    }

    // ---- 4. the money --------------------------------------------------------------

    protected string PlanMoney()
    {
        m_Give = 0;
        if (!m_Money.Physical())
        {
            if (m_Net > 0 && m_Money.Balance(m_Player) < m_Net)
                return OZT_Const.NO_MONEY;
            return "";
        }

        if (m_Net <= 0)
        {
            m_Give = -m_Net;
            return "";
        }

        array<ref OZT_NoteStack> stacks;
        OZT_ItemMoney.Stacks(m_Player, m_Gone, stacks);
        int change = OZT_ItemMoney.Pay(stacks, m_Net);
        if (change < 0)
            return OZT_Const.NO_MONEY;
        for (int i = 0; i < stacks.Count(); i++)
        {
            OZT_NoteStack s = stacks[i];
            if (s.Spend <= 0)
                continue;
            if (s.Spend >= s.Units)
                m_Gone.Insert(s.Item);
            else
                AddGrow(s.Item, -s.Spend);
        }
        m_Give = change;
        return "";
    }

    // ---- 5. the places ----------------------------------------------------------------

    // The fit rule: everything has a place; or the one thing that has none goes
    // to free hands; or the deal is refused with the count.
    //
    // A deal lays several things at once and each takes the first place that
    // fits, so the order decides what fits. Two rules (decision 11 of the plan):
    // things are laid largest first, so that small ones fill what large ones
    // leave; and when more than one thing is left without a place, everything is
    // laid once more with the first thing that needs cells -- the largest -- set
    // aside for the hands, because its cells free the most room.
    protected string PlanPlaces()
    {
        int kept = m_Grows.Count();
        string why = LayThings(false);
        if (why != "")
            return why;
        int left = m_Homeless.Count();
        if (left == 0)
            return "";

        if (left == 1)
        {
            OZT_Place hands;
            if (m_Model.PlaceInHands(m_Homeless[0], hands))
            {
                AddMake(m_Homeless[0], hands, m_HomelessUnits[0]);
                m_Res.InHands = m_Homeless[0];
                m_Homeless.Clear();
                m_HomelessUnits.Clear();
                return "";
            }
        }
        else
        {
            UnlayThings(kept);
            why = LayThings(true);
            if (why != "")
                return why;
            if (m_Homeless.Count() == 0)
                return "";
            m_Res.InHands = "";
        }

        // The count a refusal carries is the first laying's: how many things had
        // no place when the bags were used best.
        m_Res.Left = left;
        return OZT_Const.NO_SPACE;
    }

    // Lays everything the deal brings into a fresh picture of the inventory: the
    // bought lines largest first, then the change or the payout. With `aside`
    // the first thing that needs cells goes to the hands instead. What finds no
    // place is left in m_Homeless. Returns "" or the key of an internal refusal.
    protected string LayThings(bool aside)
    {
        m_Model = new OZT_InvModel(m_Player, m_Gone);
        m_Aside = aside;

        // Parts sold and parts paid shrink their stacks before anything is
        // merged into them.
        for (int g = 0; g < m_Grows.Count(); g++)
        {
            EntityAI shrunk = m_Grows[g].Stack;
            int held = m_Model.PlannedUnits(shrunk);
            m_Model.PlanUnits(shrunk, held + m_Grows[g].Units);
        }

        bool wear = OZT_Config.Get().Settings().WearBought == 1;
        array<int> order;
        LayingOrder(order);
        for (int o = 0; o < order.Count(); o++)
        {
            int b = order[o];
            string type = m_BuyClasses[b];
            EntityAI probe = m_Model.ProbeOf(type);
            if (!probe)
            {
                OZT_Log.Error("deal: the game makes nothing of class " + type);
                return OZT_Const.NO_INTERNAL;
            }
            if (m_BuyRules[b] == OZT_Const.RULE_UNIT && OZT_Stack.Countable(probe))
                PlaceUnits(type, m_BuyCounts[b], false);
            else
                PlacePieces(type, m_BuyCounts[b], wear);
        }

        // The change or the payout, in the largest notes that make the sum.
        if (m_Give > 0)
        {
            array<int> counts;
            if (!OZT_ItemMoney.Change(m_Give, counts))
            {
                OZT_Log.Error("deal: the configured notes cannot make " + m_Give.ToString());
                return OZT_Const.NO_INTERNAL;
            }
            array<ref OZT_Note> notes = OZT_Config.Get().Settings().Notes;
            for (int n = notes.Count() - 1; n >= 0; n--)
            {
                if (counts[n] > 0)
                    PlaceUnits(notes[n].ClassName, counts[n], true);
            }
        }
        return "";
    }

    // Forgets what LayThings did, so that it can be done again: the picture and
    // its probe entities, the things to make, and the merges it added. The first
    // `kept` entries of m_Grows are the deal's own: parts sold and notes paid.
    protected void UnlayThings(int kept)
    {
        m_Model.Dispose();
        m_Makes.Clear();
        m_Homeless.Clear();
        m_HomelessUnits.Clear();
        m_Res.InHands = "";
        while (m_Grows.Count() > kept)
        {
            int last = m_Grows.Count() - 1;
            m_Grows.RemoveOrdered(last);
        }
    }

    // The bought lines by the cells one thing of each takes, largest first; lines
    // of one size stay in the order they were asked in.
    protected void LayingOrder(out array<int> order)
    {
        order = new array<int>();
        array<int> areas = new array<int>();
        int count = m_BuyClasses.Count();
        for (int b = 0; b < count; b++)
        {
            int area = m_Model.AreaOf(m_BuyClasses[b]);
            areas.Insert(area);
        }
        for (int n = 0; n < count; n++)
        {
            int best = -1;
            for (int i = 0; i < count; i++)
            {
                if (order.Find(i) > -1)
                    continue;
                if (best < 0)
                {
                    best = i;
                    continue;
                }
                if (areas[i] > areas[best])
                    best = i;
            }
            order.Insert(best);
        }
    }

    // The hands for the thing set aside, once per laying.
    protected bool AsideToHands(string type, out OZT_Place place)
    {
        place = null;
        if (!m_Aside)
            return false;
        m_Aside = false;
        if (!m_Model.PlaceInHands(type, place))
            return false;
        m_Res.InHands = type;
        return true;
    }

    // `units` of a countable class: onto the stacks of the class the player
    // keeps, then as new stacks of at most the class's maximum.
    protected void PlaceUnits(string type, int units, bool notes)
    {
        int left = units;
        array<EntityAI> stacks;
        array<int> room;
        m_Model.StacksWithRoom(type, notes, stacks, room);
        for (int i = 0; i < stacks.Count() && left > 0; i++)
        {
            int take = room[i];
            if (take > left)
                take = left;
            EntityAI onto = stacks[i];
            AddGrow(onto, take);
            int held = m_Model.PlannedUnits(onto);
            m_Model.PlanUnits(onto, held + take);
            left = left - take;
        }
        if (left <= 0)
            return;

        EntityAI probe = m_Model.ProbeOf(type);
        int most = OZT_Stack.Max(probe);
        if (most < 1)
            most = 1;
        while (left > 0)
        {
            int n = left;
            if (n > most)
                n = most;
            OZT_Place place;
            bool placed = AsideToHands(type, place);
            if (!placed)
                placed = m_Model.PlaceInCargo(type, notes, place);
            if (placed)
                AddMake(type, place, n);
            else
            {
                m_Homeless.Insert(type);
                m_HomelessUnits.Insert(n);
            }
            left = left - n;
        }
    }

    // `count` pieces of a class: a free slot of the character first when bought
    // gear is worn (decision 4), then a cargo. A thing that goes onto a slot
    // needs no cells and is never the one set aside.
    protected void PlacePieces(string type, int count, bool wear)
    {
        for (int i = 0; i < count; i++)
        {
            OZT_Place place;
            bool placed = false;
            if (wear)
                placed = m_Model.PlaceOnSlot(type, place);
            if (!placed)
                placed = AsideToHands(type, place);
            if (!placed)
                placed = m_Model.PlaceInCargo(type, false, place);
            if (placed)
            {
                AddMake(type, place, 0);
                continue;
            }
            m_Homeless.Insert(type);
            m_HomelessUnits.Insert(0);
        }
    }

    protected void AddGrow(EntityAI stack, int units)
    {
        OZT_Grow g = new OZT_Grow();
        g.Stack = stack;
        g.Units = units;
        m_Grows.Insert(g);
    }

    protected void AddMake(string type, OZT_Place place, int units)
    {
        OZT_Make m = new OZT_Make();
        m.ClassName = type;
        m.Place = place;
        m.Units = units;
        m_Makes.Insert(m);
    }

    // ---- 6. the commit --------------------------------------------------------------------

    protected string Commit()
    {
        // Money that is not items leaves first: if it cannot, nothing has
        // changed yet.
        if (!m_Money.Physical() && m_Net > 0)
        {
            if (!m_Money.Take(m_Player, m_Net, "deal"))
                return OZT_Const.NO_MONEY;
        }

        // One script call from here on.
        for (int d = 0; d < m_Gone.Count(); d++)
        {
            if (m_Gone[d])
                GetGame().ObjectDelete(m_Gone[d]);
        }
        for (int s = 0; s < m_Grows.Count(); s++)
        {
            if (m_Grows[s].Units < 0)
                OZT_Stack.Add(m_Grows[s].Stack, m_Grows[s].Units);
        }
        for (int m = 0; m < m_Makes.Count(); m++)
            CreateOne(m_Makes[m]);
        for (int g = 0; g < m_Grows.Count(); g++)
        {
            if (m_Grows[g].Units > 0)
                Merge(m_Grows[g].Stack, m_Grows[g].Units);
        }

        if (!m_Money.Physical() && m_Net < 0)
            m_Money.Give(m_Player, -m_Net, "deal");

        string uid = Uid();
        int now = GetGame().GetTime();
        s_Last.Set(uid, now);
        m_Res.Balance = m_Money.Balance(m_Player);

        string line = "deal: " + uid + " at '" + m_Trader.Id + "' net " + m_Net.ToString();
        line = line + " (" + m_Money.Id() + "):" + m_Lines;
        OZT_Log.Info(line);
        return "";
    }

    protected void CreateOne(OZT_Make make)
    {
        EntityAI made = OZT_InvModel.Make(m_Player, make.Place, make.ClassName);
        if (!made)
            made = Rescue(make);
        else if (!OZT_InvModel.Stands(made, make.Place))
            OZT_Log.Error("deal defect: " + make.ClassName + " was planned at " + make.Place.Text() + " and stands elsewhere");

        if (made && make.Units > 0)
            OZT_Stack.Set(made, make.Units);
    }

    // The engine refused a planned place. A paid thing is never lost: the
    // engine's own search, then the ground at the player's feet; and the log
    // says where the plan was wrong.
    protected EntityAI Rescue(OZT_Make make)
    {
        EntityAI made = m_Player.GetHumanInventory().CreateInInventory(make.ClassName);
        string how = "by the engine's own search";
        if (!made)
        {
            vector feet = m_Player.GetPosition();
            made = EntityAI.Cast(GetGame().CreateObjectEx(make.ClassName, feet, ECE_PLACE_ON_SURFACE));
            how = "at the player's feet";
        }
        string msg = "deal defect: the engine refused " + make.ClassName + " at " + make.Place.Text();
        msg = msg + "; it was made " + how;
        OZT_Log.Error(msg);
        return made;
    }

    // More units onto a stack the player keeps. A quantity stack takes the
    // weighted condition of what it held and the pristine units it gets, as the
    // game's own combine does; a pile of rounds counts rounds.
    protected void Merge(EntityAI stack, int units)
    {
        if (!stack)
            return;
        if (Magazine.Cast(stack))
        {
            OZT_Stack.Add(stack, units);
            return;
        }
        float held = OZT_Stack.Units(stack);
        float health = stack.GetHealth01("", "");
        float mixed = (health * held + units) / (held + units);
        OZT_Stack.Add(stack, units);
        stack.SetHealth01("", "", mixed);
    }
}
```

```c
    // quote / deal: [trader=<id>] [sell=Class[:units][#nth],...] [sellnear=Class]
    // [buy=Class:n,...] [net=<n>]
    //
    // `sell` names things the player carries; `sellnear` a thing lying within
    // five metres (to ask for something that is not the player's). A quote runs
    // every check and the whole plan and changes nothing. A deal is sent through
    // the service handler, as a client's is; without net= it carries the net the
    // server itself quotes, as an honest client would.
    static bool OpDeal(PlayerBase player, map<string, string> args, bool commit, out string detail)
    {
        OZT_DealReq req = new OZT_DealReq();
        req.Trader = Arg(args, "trader", "stand");

        array<string> names;
        array<int> counts;
        array<int> nths;
        Items(Arg(args, "sell", ""), names, counts, nths);
        for (int s = 0; s < names.Count(); s++)
        {
            EntityAI sold = Carried(player, names[s], nths[s]);
            if (!sold)
            {
                detail = "the player carries no " + names[s] + " number " + nths[s].ToString();
                return false;
            }
            req.Sells.Insert(SellOf(sold, counts[s]));
        }

        string near = Arg(args, "sellnear", "");
        if (near != "")
        {
            EntityAI lying = Nearby(player, near);
            if (!lying)
            {
                detail = "no " + near + " lies within five metres";
                return false;
            }
            req.Sells.Insert(SellOf(lying, 0));
        }

        Items(Arg(args, "buy", ""), names, counts, nths);
        for (int b = 0; b < names.Count(); b++)
        {
            OZT_WireBuy buy = new OZT_WireBuy();
            buy.ClassName = names[b];
            buy.Count = counts[b];
            if (buy.Count < 1)
                buy.Count = 1;
            req.Buys.Insert(buy);
        }

        bool ok;
        string why;
        string err;
        string json;
        JsonFileLoader<OZT_DealReq>.MakeData(req, json, err, false);
        string quoted = OZT_Deal.Run(player, json, false, ok, why);
        if (!commit)
        {
            SaveAnswer(quoted);
            detail = "quote " + Told(quoted, ok, why);
            return true;
        }

        if (args.Contains("net"))
            req.Net = Arg(args, "net", "0").ToInt();
        else
        {
            OZT_DealRes q = new OZT_DealRes();
            JsonFileLoader<OZT_DealRes>.LoadData(quoted, q, err);
            req.Net = q.Net;
        }
        JsonFileLoader<OZT_DealReq>.MakeData(req, json, err, false);
        string body = Ask(player, OZT_Const.OP_DEAL, json, ok, why);
        detail = "deal " + Told(body, ok, why);
        return true;
    }

    static OZT_WireSell SellOf(EntityAI e, int count)
    {
        OZT_WireSell line = new OZT_WireSell();
        int low;
        int high;
        e.GetNetworkID(low, high);
        line.Low = low;
        line.High = high;
        line.Count = count;
        return line;
    }

    // The nearest thing of a class that lies loose within five metres.
    static EntityAI Nearby(PlayerBase player, string type)
    {
        array<Object> found = new array<Object>();
        vector here = player.GetPosition();
        GetGame().GetObjectsAtPosition(here, 5, found, null);
        for (int i = 0; i < found.Count(); i++)
        {
            EntityAI e = EntityAI.Cast(found[i]);
            if (e && e.GetType() == type && !e.GetHierarchyParent())
                return e;
        }
        return null;
    }

    // An answer of the deal in one line.
    static string Told(string body, bool ok, string why)
    {
        OZT_DealRes res = new OZT_DealRes();
        string err;
        if (body != "")
            JsonFileLoader<OZT_DealRes>.LoadData(body, res, err);
        string s;
        if (ok)
            s = "ok=yes";
        else
            s = "ok=no why=" + why;
        s = s + " net=" + res.Net.ToString() + " paid=" + res.Paid.ToString() + " received=" + res.Received.ToString();
        s = s + " balance=" + res.Balance.ToString() + " hands=" + res.InHands + " left=" + res.Left.ToString();
        return s;
    }
```
